# AClad — состояние и хэндофф (ЧИТАТЬ ПЕРВЫМ)

> **Это проект AClad — раскладка облицовки НВФ (этап 2 фасадного
> направления), ОТДЕЛЬНЫЙ бандл. НЕ путать с LD/физикой.** Выделен из
> Facades 22.07 по просьбе Германа: боевой этап 1 (AFacades: зоны/
> ведомости) ставится один раз, раскладка переустанавливается при
> каждой итерации. Грабли среды/сборки/push — `ATableSpec/docs/NEXT.md`
> (обязательны), методика фидбэка — `ABlockGen/docs/NEXT.md`, история
> направления и этапа 1 — `Facades/docs/NEXT.md`. Ветка общая:
> `feat/auto-reactor`; `main` — только по «Пушим».

## TL;DR
- **Что:** команда **ATCLAD** — раскладка облицовки универсальным
  блоком (кассетой) по зонам ATFZONE и/или замкнутым полилиниям.
  Гибрид: тонкий C# (`ACladPlugin.dll`) + замороженный движок
  (`clad_engine.exe`); бандл `AClad.bundle` в релизе `latest`.
- **Действующее ТЗ — письмо Германа 22.07** (дословно + статус:
  `docs/CLADDING.md` §ТЗ 22.07). Оно ЗАМЕНЯЕТ прежние В1–В8 при
  противоречиях: п.1.2 (целая по центру простенка, в обе стороны,
  кусок <300 — сдвиг на полплиты) вместо В5; режимов «Проемы/Край»
  больше нет — алгоритм один.
- **Связка с AFacades:** контракт данных общий (Xrecord «ATFZONE» на
  штриховках/марках читаем, свой ключ «ATCLAD» пишем;
  `<dwg>_fzones.json` — геометрия зон), реализация продублирована
  СОЗНАТЕЛЬНО (модули развязаны, обновляются независимо).
- **Статус (22.07a):** движок по ТЗ 22.07: 1.1 ✓, 1.2 ✓
  (`_seg_centered`), 1.3 ✓ без хвоста «целая шире окна», 1.5 ✓ (швы
  вокруг проёмов со всех сторон), 1.6 ✓ (`_seg_from_corner` — от угла
  целыми), 2.1–2.5 ✓ в диалоге ATCLAD; 36 проверок движка + 12
  юнитов CLI. НЕ реализовано: **1.4/2.6** (точки горизонтальных
  рустов → локальные вертикальные датумы над окнами) и **1.3-хвост**
  (целая шире окна с перекрытием соседних пролётов) — СЛЕДУЮЩИЙ
  ЗАХОД. Рантайм у Германа не проверялся, сборка AClad ещё не
  выкладывалась.

- `engine/cladding_plan.py` — правила раскладки (ТЗ 22.07 в
  докстринге); `engine/clad_engine.py` — CLI (op=cladding, группировка
  голых контуров по вложенности — своя, от facade_zones НЕ зависит);
  `engine/test_*.py` — юниты (`PYTHONUTF8=1`, запуск из engine).

- `docs/CLADDING.md` — ТЗ дословно + модель данных/алгоритм;
  `docs/ATCLAD_manual.md` — инструкция Герману.
