# Инструкции для проектного отдела

Два отдельных документа Word:

- [Полное руководство по фасадным модулям](Facades_User_Manual.docx) — от учебного фасада до ведомостей, старых зон и поиска ошибок; включает пример с 15 окнами.
- [Скачивание и установка в AutoCAD 2024](Install_AutoCAD_2024.docx) — три архива одного выпуска, обновление, первый запуск и откат. [Та же инструкция в браузере](INSTALL_AUTOCAD_2024.md).

Документы подготовлены для [выпуска build-113](https://github.com/zinchenko-denis/AutoCAD/releases/tag/build-113) от 28 октября 2026 года.
Исправления в исходниках сами по себе не обновляют установочные архивы. Точный
проверенный код, CI и опубликованный выпуск — в [текущем плане](../CURRENT_MILESTONES.md).
Для повторной установки заменяются все три фасадных модуля. Полное руководство
содержит 24 контрольных сценария, включая внешние углы, швеллеры, ATTILE 245×35,85 и 563,55×588,25 мм и отдельный
автор узла 2026-10-08.2. Полный нативный проход №113 ещё не выполнен; живой отказ ATTILE на типовом
блоке остаётся незакрытым. Результаты синтетических тестов не заменяют
выполнение сценариев в AutoCAD. Оба DOCX передаются также непосредственно в чате,
чтобы проектный отдел мог получить их без загрузки из GitHub.

## Поддержка документов

Полное руководство сохраняет 20 глав и десять иллюстраций прежнего
[учебного руководства](../facades_beginner_3009/). Учебные входы повторно
проверены; рисунки показывают результаты ядра, а не экран живого AutoCAD.
Дополнительный рисунок и координаты фасада с окнами взяты из
[короткого маршрута](../pilot/README.md). Исходники текста и сборщиков
сохранены рядом с DOCX; архивное руководство не переписывается.

```bash
python3 docs/user/build_manual.py
python3 docs/user/build_install.py
```

Требуется `python-docx` и зависимости, указанные в сборщике полного
руководства. После изменений DOCX следует отрендерить и проверить все
страницы. PDF и PNG этого просмотра, подробные логи и повторные квитанции
в репозиторий не добавляются.
