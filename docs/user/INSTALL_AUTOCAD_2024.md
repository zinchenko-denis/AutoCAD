# Установка фасадных модулей AutoCAD

Для Германа и проектного отдела. Выпуск **build-112 от 15 октября 2026 года**. Обновите все три модуля вместе. Пакеты допускают загрузку в полном AutoCAD 2021–2024 на Windows 64 bit; это не подтверждает испытание каждой версии. Основная нативная проверка запланирована в AutoCAD 2024. LT, Mac и AutoCAD 2025+ не поддерживаются. Python устанавливать не нужно.

## Скачать комплект

Откройте [выпуск build-112 на GitHub](https://github.com/zinchenko-denis/AutoCAD/releases/tag/build-112) и скачайте три файла. Пункт Code → Download ZIP содержит исходники, для установки он не нужен.

| Файл | Назначение |
|---|---|
| [AFacades.bundle.zip](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-112/AFacades.bundle.zip) | Зоны и ведомости |
| [AClad.bundle.zip](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-112/AClad.bundle.zip) | Раскладка облицовки |
| [AFrame.bundle.zip](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-112/AFrame.bundle.zip) | Подсистема и параметры проекта |

## Установить

1. Сохраните резервную копию DWG вместе с его файлом `_fzones.json`. Закройте **все окна AutoCAD**.
2. В свойствах скачанных ZIP нажмите **Разблокировать**, если этот пункт есть. Распакуйте архивы.
3. В адресной строке Проводника откройте `%APPDATA%\Autodesk\ApplicationPlugins`. Перенесите прежние `AFacades.bundle`, `AClad.bundle` и `AFrame.bundle` в резервную папку **вне ApplicationPlugins**. Поместите на их место три новые папки целиком. ATableSpec и ABlockGen не меняйте.
4. Проверьте путь: `ApplicationPlugins\AFrame.bundle\PackageContents.xml`. Так же проверьте два других модуля. Лишнего уровня `AFrame.bundle\AFrame.bundle` быть не должно. Если раньше была общая установка, уберите дубли этих трёх модулей также из `%PROGRAMDATA%\Autodesk\ApplicationPlugins` и `%PROGRAMFILES%\Autodesk\ApplicationPlugins`.
5. Запустите AutoCAD. При запросе доверия проверьте путь к новым файлам и разрешите их загрузку. Глобальную защиту загрузки не отключайте.

## Проверить загрузку

Нажмите **F2**: должны загрузиться AFacades, AClad и AFrame без предупреждения о смешанных версиях. В каждой папке откройте `Contents\net48\build-info.json`: **build = 112**, а полный `sha` одинаков во всех трёх файлах и совпадает с описанием выпуска. Значение пакета 0.1.0 номер выпуска не определяет.

Введите **ATFZONE**, затем Esc; повторите для **ATTILE** и **ATFRAME**. Команды должны распознаться. Если меню не появилось, сохраните F2 и точную версию AutoCAD; профиль и чужие меню не удаляйте.

## Короткая проверка после установки

Работайте с копией DWG и парным JSON. Пройдите **ATFZONE → ATTILE → ATFRAME → ATFTABLE → сохранить → закрыть → открыть**. Старую зону без снимка сначала примите через ATFZONEACCEPT по полному руководству. Undo не восстанавливает внешний JSON: при откате возвращайте резервную пару вместе.

В ATFRAME выберите вертикальную систему и «внешние углы здания». Укажите левую наружную границу учебной стены, завершите выбор Enter и задайте вынос **L = 230 мм**, если он ещё не задан параметрами проекта. Ожидаются ось на границе и вторая ось **330 мм внутрь**; швеллер **430×100 мм** выходит на 50 мм за каждую ось, его середина по высоте совпадает с кронштейнами. Это согласованная условная схема; реальные монтажные смещения не моделируются. В ортогональной и межэтажной схемах первый ряд находится на 330 мм внутрь, швеллера нет.

Все 23 контрольных сценария, включая прежние дробные размеры, отмену, ведомости, повторное открытие и библиотечный узел, приведены в **Facades_User_Manual.docx**, передаваемом вместе с этой памяткой. В установочных ZIP нет готового проверенного DWG динамического узла; ранее переданный закрытый тестовый комплект остаётся отдельным.

**Статус проверки.** Программные и синтетические проверки пройдены. Полный проход этого выпуска в AutoCAD ещё не выполнен. Прежний отказ ATTILE на типовом динамическом блоке остаётся незакрытым; в №112 улучшена диагностика причины. Отказ обычного построения не считается успешной проверкой.

## Если возникла ошибка

Передайте Денису номер 112, точную версию AutoCAD, команду, последовательность действий и **весь текст F2**. Для ATTILE нужны исходная причина, имя свойства, запрошенный и полученный размеры. Приложите разрешённую к передаче копию DWG и JSON. Если нужен откат, закройте AutoCAD и верните три резервные папки целиком.
