# Установка фасадных модулей в AutoCAD 2024

Для Германа и проектного отдела. Эта инструкция помогает обновить зоны, облицовку и каркас, затем проверить загрузку. Нужен полный AutoCAD 2024 для Windows 64 bit. LT, Mac и AutoCAD 2025 или новее этим комплектом не поддерживаются. Python и средства разработки устанавливать не нужно.

**Редакция от 6 октября 2026 года. Устанавливайте выпуск build-109.** В него включены исправления зон и облицовки, торцов направляющих у окон, резки хлыстов, боковых стоек верхних окон и дробных переносов фасада. Добавлены команды тестовой библиотеки динамических узлов. Красные пометки непроверенных участков требуют проверки инженером; работа нового узла в живом AutoCAD ещё должна быть проверена по полному руководству.

## Скачать три архива одного выпуска

1. Откройте [выпуск build-109 на GitHub](https://github.com/zinchenko-denis/AutoCAD/releases/tag/build-109). Репозиторий открытый, вход в GitHub для скачивания не нужен.
2. Проверьте номер **build-109** в заголовке страницы. Не выбирайте другой номер только потому, что он помечен Latest. Раскройте раздел **Assets** под описанием выпуска.
3. Скачайте все три файла из таблицы. **Code → Download ZIP** и **Source code** содержат исходники, а не готовую программу.

| Скачать файл | Назначение |
|---|---|
| [AFacades.bundle.zip](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-109/AFacades.bundle.zip) | Зоны и ведомости |
| [AClad.bundle.zip](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-109/AClad.bundle.zip) | Облицовка |
| [AFrame.bundle.zip](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-109/AFrame.bundle.zip) | Каркас и параметры проекта |

ATableSpec и ABlockGen оставьте как есть. Три фасадных модуля обновляйте вместе, даже если раньше меняли только один из них.

## Заменить установленные папки

4. Закройте все окна AutoCAD. Сохраните резервную копию рабочего DWG вместе с соседним файлом `<имя чертежа>_fzones.json`.
5. В свойствах каждого ZIP отметьте **Разблокировать**, если Windows показывает этот пункт. Нажмите Применить, затем распакуйте архивы.
6. В адресной строке Проводника откройте `%APPDATA%\Autodesk\ApplicationPlugins`. Старые папки `AFacades.bundle`, `AClad.bundle` и `AFrame.bundle` перенесите в резервную папку **вне ApplicationPlugins**. Положите на их место три новые папки целиком. Не оставляйте старые DLL внутри новых папок.
7. Проверьте, что файл лежит прямо по пути `ApplicationPlugins\AFrame.bundle\PackageContents.xml`. Так же проверьте два других модуля. Лишнего уровня вроде `AFrame.bundle\AFrame.bundle` быть не должно.

## Проверить первый запуск

8. Запустите AutoCAD. При запросе доверия проверьте путь к установленному комплекту и разрешите его загрузку. Глобальную защиту загрузки не отключайте.
9. Нажмите **F2** и проверьте сообщения загрузки AFacades, AClad и AFrame. Предупреждение о разных или отсутствующих версиях означает, что обновление нужно закончить. В каждой папке откройте `Contents\net48\build-info.json`: поля `build` и `sha` должны совпадать у всех трёх модулей и соответствовать выбранному выпуску: `build` = `109`, а `sha` — исходному коммиту из описания build-109.
10. На копии того же DWG повторите **ATFZONE** с прежними контурами, затем **ATTILE** с прежним образцом. Сохраните результат, полностью перезапустите AutoCAD и повторите обе команды. При сбое передайте текст F2 и номер сборки. Полный маршрут зон, облицовки, каркаса, ведомостей, повторного открытия и узла «три из пяти» — в [полном руководстве выпуска 109](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-109/Facades_User_Manual.docx).

Если раньше ставили плагины для всех пользователей, проверьте также `%PROGRAMDATA%\Autodesk\ApplicationPlugins` и `%PROGRAMFILES%\Autodesk\ApplicationPlugins`: там не должно остаться вторых копий этих трёх модулей. Для общей установки может потребоваться администратор.

## Что проверять после установки

Сначала пройдите основную цепочку: **ATFZONE → ATTILE → ATFRAME → ведомости → сохранить → закрыть → открыть**. Затем повторите 13 регрессионных сценариев из полного руководства: прежние ошибки не считаются исправленными на рабочем месте, пока соответствующий обычный сценарий не выполнен.

Для динамического узла используйте отдельно переданный тестовый LISP и его инструкцию. В трёх установочных ZIP нет готового проверенного DWG узла. `ATFNODE` строит справочную схему слоёв; библиотека использует `ATFNODEIMPORT`, `ATFNODEEDIT`, `ATFNODEDEMO` и `ATFNODETEST`. После создания узла измените три экземпляра из пяти и проверьте геометрию, размеры и марки; два остальных должны остаться прежними.

## Открыть прежний чертёж

Работайте сначала с копией. Держите DWG и его `_fzones.json` вместе. Если использовали **Сохранить как**, скопируйте исходный JSON и переименуйте копию под новый DWG: например, `Фасад_тест.dwg` и `Фасад_тест_fzones.json`. Автоматического переименования JSON пока нет.

Если программа сообщает, что у старой зоны нет сохранённого снимка контуров, запустите **ATFZONEACCEPT** или нажмите **Принять старую зону** на ленте. Проверьте контуры и подтвердите принятие их текущей геометрии. Исходный JSON обязателен. Команда сохраняет объекты и марку зоны; облицовку, каркас и ведомости после неё пересчитайте. Повреждённые или неоднозначно скопированные зоны автоматически не принимаются.

**Undo не возвращает внешний JSON.** Для полного отката восстановите резервную пару DWG и JSON вместе.

## Если возникла проблема

- **Панель снова пропала.** Скопируйте F2 после запуска и укажите, какая панель отсутствует. Причина ещё не подтверждена; диагностика загрузки панелей и исправление очистки меню включены в выпуск 109. Сообщение `ACAD:Фасады`, если оно повторится, фиксируйте отдельно; оно ещё не признано устранённым в живом AutoCAD.
- **Команда неизвестна или вкладки нет.** Проверьте версию AutoCAD, структуру трёх папок, наличие `PackageContents.xml`, сообщения F2 и доверие к файлам. После исправления полностью перезапустите AutoCAD.
- **Версии различаются.** Закройте AutoCAD, уберите дубли и снова установите три папки одного выпуска. Не продолжайте тест со смешанным комплектом.
- **Файл заблокирован.** Передайте администратору точное сообщение. При необходимости он добавит доверие только к проверенному каталогу, сохраняя общую защиту.
- **Нужен прежний выпуск.** Закройте AutoCAD и верните три резервные папки целиком. При откате чертежа восстановите также его парный JSON.

Для разбора ошибки передайте Денису номер выпуска, версию AutoCAD, команду, последний шаг и текст F2. Для ошибки геометрии приложите разрешённую к передаче копию DWG вместе с её JSON.
