# Установка фасадных модулей в AutoCAD 2024

Для Германа и проектного отдела. Эта инструкция помогает обновить зоны, облицовку и каркас, затем проверить загрузку. Нужен полный AutoCAD 2024 для Windows 64 bit. LT, Mac и AutoCAD 2025 или новее этим комплектом не поддерживаются. Python и средства разработки устанавливать не нужно.

**Редакция от 9 октября 2026 года. Устанавливайте выпуск build-111.** Он включает исправления 8–9 октября, которых нет в №110: разные дробные размеры облицовки больше не используют один прототип; исключено округление при преобразовании значения в целое; проверка геометрии больше не принимает расхождение 0,15 мм. Исправленный автор узла 2026-10-08.2 передаётся отдельным тестовым ZIP. Проверка в AutoCAD по этой инструкции ещё должна подтвердить обычные рабочие сценарии. Отказ построения не считается успешным испытанием.

## Скачать три архива одного выпуска

1. Откройте [выпуск build-111 на GitHub](https://github.com/zinchenko-denis/AutoCAD/releases/tag/build-111). Репозиторий открытый, вход в GitHub для скачивания не нужен.
2. Проверьте номер **build-111** в заголовке страницы. Не выбирайте другой номер только потому, что он помечен Latest. Раскройте раздел **Assets** под описанием выпуска.
3. Скачайте все три файла из таблицы. **Code → Download ZIP** и **Source code** содержат исходники, а не готовую программу.

| Скачать файл | Назначение |
|---|---|
| [AFacades.bundle.zip](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-111/AFacades.bundle.zip) | Зоны и ведомости |
| [AClad.bundle.zip](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-111/AClad.bundle.zip) | Облицовка |
| [AFrame.bundle.zip](https://github.com/zinchenko-denis/AutoCAD/releases/download/build-111/AFrame.bundle.zip) | Каркас и параметры проекта |

ATableSpec и ABlockGen оставьте как есть. Три фасадных модуля обновляйте вместе, даже если раньше меняли только один из них.

## Заменить установленные папки

4. Закройте все окна AutoCAD. Сохраните резервную копию рабочего DWG вместе с соседним файлом `<имя чертежа>_fzones.json`.
5. В свойствах каждого ZIP отметьте **Разблокировать**, если Windows показывает этот пункт. Нажмите Применить, затем распакуйте архивы.
6. В адресной строке Проводника откройте `%APPDATA%\Autodesk\ApplicationPlugins`. Старые папки `AFacades.bundle`, `AClad.bundle` и `AFrame.bundle` перенесите в резервную папку **вне ApplicationPlugins**. Положите на их место три новые папки целиком. Не оставляйте старые DLL внутри новых папок.
7. Проверьте, что файл лежит прямо по пути `ApplicationPlugins\AFrame.bundle\PackageContents.xml`. Так же проверьте два других модуля. Лишнего уровня вроде `AFrame.bundle\AFrame.bundle` быть не должно.

## Проверить первый запуск

8. Запустите AutoCAD. При запросе доверия проверьте путь к установленному комплекту и разрешите его загрузку. Глобальную защиту загрузки не отключайте.
9. Нажмите **F2** и проверьте сообщения загрузки AFacades, AClad и AFrame. Предупреждение о разных или отсутствующих версиях означает, что обновление нужно закончить. В каждой папке откройте `Contents\net48\build-info.json`: поля `build` и `sha` должны совпадать у всех трёх модулей: `build` = `111`, а `sha` — исходный коммит из описания build-111.
10. На копии прежнего DWG сначала проверьте парный JSON. Для старой зоны без снимка выполните **ATFZONEACCEPT** по разделу ниже; не создавайте поверх неё дубликат. Затем повторите **ATFZONE** при изменённых контурах и **ATTILE** с прежним образцом. Сохраните результат, полностью перезапустите AutoCAD и повторите проверку. Полный маршрут и ожидаемые результаты — в документе **Facades_User_Manual.docx**, который Денис передаёт вместе с этой инструкцией. Он также доступен в выпуске build-111.

Если раньше ставили плагины для всех пользователей, проверьте также `%PROGRAMDATA%\Autodesk\ApplicationPlugins` и `%PROGRAMFILES%\Autodesk\ApplicationPlugins`: там не должно остаться вторых копий этих трёх модулей. Для общей установки может потребоваться администратор.

## Что проверять после установки

Сначала пройдите основную цепочку: **ATFZONE → ATTILE → ATFRAME → ведомости → сохранить → закрыть → открыть**. Затем повторите 17 сценариев раздела 2.3 полного руководства. Особо проверьте прежние отказы **245×35,85** и **821,87×600 мм**: нужный размер должен действительно построиться. Если он снова округляется или команда отказывает, сохраните F2 и отметьте сценарий как непройденный.

Для динамического узла распакуйте отдельно переданный тестовый ZIP с инструкцией и LISP. После APPLOAD проверьте редакцию автора **2026-10-08.2** в F2. В трёх установочных ZIP нет готового проверенного DWG узла. `ATFNODE` строит справочную схему слоёв; библиотека использует `ATFNODEIMPORT`, `ATFNODEEDIT`, `ATFNODEDEMO` и `ATFNODETEST`. После создания узла измените три экземпляра из пяти и проверьте геометрию, размеры и марки; два остальных должны остаться прежними. Повторите проверку после сохранения и открытия.

## Открыть прежний чертёж

Работайте сначала с копией. Держите DWG и его `_fzones.json` вместе. Если использовали **Сохранить как**, скопируйте исходный JSON и переименуйте копию под новый DWG: например, `Фасад_тест.dwg` и `Фасад_тест_fzones.json`. Автоматического переименования JSON пока нет.

Если программа сообщает, что у старой зоны нет сохранённого снимка контуров, запустите **ATFZONEACCEPT** или нажмите **Принять старую зону** на ленте. Проверьте контуры и подтвердите принятие их текущей геометрии. Исходный JSON обязателен. Команда сохраняет объекты и марку зоны; облицовку, каркас и ведомости после неё пересчитайте. Повреждённые или неоднозначно скопированные зоны автоматически не принимаются.

**Undo не возвращает внешний JSON.** Для полного отката восстановите резервную пару DWG и JSON вместе.

## Если возникла проблема

- **Панель снова пропала.** Скопируйте F2 после запуска и укажите, какая панель отсутствует. Диагностика загрузки панелей и исправление очистки меню сохранены. Сообщение `ACAD:Фасады`, если оно повторится, фиксируйте отдельно; оно ещё не признано устранённым в живом AutoCAD.
- **Команда неизвестна или вкладки нет.** Проверьте версию AutoCAD, структуру трёх папок, наличие `PackageContents.xml`, сообщения F2 и доверие к файлам. После исправления полностью перезапустите AutoCAD.
- **Версии различаются.** Закройте AutoCAD, уберите дубли и снова установите три папки одного выпуска. Не продолжайте тест со смешанным комплектом.
- **Файл заблокирован.** Передайте администратору точное сообщение. При необходимости он добавит доверие только к проверенному каталогу, сохраняя общую защиту.
- **Нужен прежний выпуск.** Закройте AutoCAD и верните три резервные папки целиком. При откате чертежа восстановите также его парный JSON.

Для разбора ошибки передайте Денису номер выпуска, версию AutoCAD, команду, последний шаг и весь текст F2. При ATTILE сохраните строки с запрошенным/фактическим размером, типом свойства, единицами и допустимыми значениями. Для автора узла нужны также AFN STAGE, AFN COMMAND, AFN LAST PROMPT и UNDOCTL. Приложите разрешённую к передаче копию DWG вместе с её JSON.
