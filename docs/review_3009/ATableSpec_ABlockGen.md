## Культура и JSON

Реальные C# NumClean и ParseD скомпилированы из текущих файлов, выполнены в ru-RU/en-US/de-DE. Во всех трёх `1499.99999999998 → 1500`, `1500,25 == 1500.25`. Ошибка S1 связана с отсутствием вызова NumClean в реакторе, а не с русской локалью.

CLI ATableSpec с именем блока, содержащим кавычки, backslash, Ω, и длиной `1500,00` вернул корректный JSON `[1500,1]`, exit0. Повреждённый JSON и NaN-атрибут дали exit1+traceback без JSON. ABlockGen на повреждённый JSON и неизвестный op вернул структурированный `{ok:false,error:...}`, exit1. Подробности в `json_cli_probes.json`.

C# вызов движка в обоих модулях синхронный, без таймаута: `ReportReactor.cs:534–538`, `ReportCommand.cs:542–546`, `VitrageCommand.cs:481–486`. Это известный архитектурный риск зависания UI, не воспроизведённое зависание. Не утверждать, что Python уже повисал.
