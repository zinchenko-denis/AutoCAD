# NordFOX MLK-v-300: повторная сверка АТР с AFrame

Дата: 30.09.2026. Базовый код: `5cdd34ec4dc963d12b58b0fe508617f29a4944d6`.
Источник: приватный `atspec-testdata/docs/facades_atr/ATR_NordFOX_MLKv300_v3.76_2016.pdf`,
редакция **v3.76, 2016**, 93 страницы. Номера PDF и печатные номера листов
в проверенных местах совпадают. Прежний конспект:
[atr_nordfox_mlk_2016.md](../../Facades/docs/kb/atr_nordfox_mlk_2016.md).

## Результат

NordFOX не реализован как система AFrame. В форме нет выбора производителя,
в `systems.json` нет NordFOX, расчётная модель и сечения относятся к переданным
расчётам «Вектор». Поэтому отличия NordFOX от генерируемого каркаса сами по себе
не являются регрессиями поддержанной системы. Они показывают, почему нельзя
объявить поддержку NordFOX добавлением названия или заменой марок профилей.

Прежний конспект содержал подтверждённые ошибки и пропуски: привязку шага
кронштейнов ко всем вертикальным швам, превращение иллюстративного размера
3000×1000 в предел формата, арифметическую линейку вылетов, чрезмерное
упрощение фиксированных/подвижных узлов и горизонтальных элементов.
По отдельному разрешению конспект исправлен. Продуктовые файлы этим аудитом
не менялись. Изображения и полные тексты приватного альбома в репозиторий
не добавлены.

Новые ошибки входного API воспроизведены отдельно: неизвестный `sub_type`
и неизвестное имя внутри словаря `system` принимались как успешные запросы.
Они переданы в архитектурный отчёт как одна группа дефектов контракта;
не следует повторно считать их «ошибками реализации NordFOX».

Дополнения к пониманию облицовки:

- На л.17/44–50 планка под кромку плиты и горизонтальный профиль под
  клипсу - разные элементы. Клипса наклеивается на плиту; её зацепление
  имеет собственный компенсационный зазор. Это не обычный кляммер AFrame.
- П.5.6.5 (л.20) допускает обоснованный вариант без клипс и дополнительных
  горизонтальных профилей в зависимости от формата, толщины и ветра.
  Он не даёт универсального разрешения убрать планки.
- Кассетный вариант имеет каретки, икли, клеевую рамку и дополнительное
  верхнее крепление (л.20,60–65). Материал «керамогранит» сам по себе
  не выбирает между этими способами крепления.
- Упоминание композитного материала в откосах (л. 79) не делает весь альбом
  решением для фасадных АКП. Термин «кляммеры» в общем перечне рабочей
  документации на л.18 также не заменяет конструкцию показанных узлов.

## Реальные воспроизведения API

Артефакты без приватной геометрии:

- [nordfox_contract_probe.py](../../tools/atr_review_3009/nordfox_contract_probe.py);
- [nordfox_contract_results.json](../../tools/atr_review_3009/nordfox_contract_results.json).

Основа запроса: прямоугольник 1200×9000 мм, `joints_x=[300,900]`,
горизонтальные ряды от 0 до 9000 через 600, явный пустой список внешних углов,
`cladding=porcelain`, без указанных перекрытий. Полный вход записан в JSON.
Расчётный вариант: `system=Вектор-1`, район II, местность B, высота 30 м,
масса 25 кг/м², вынос 230 мм, анкер 3000 Н.

| Вход на базовом HEAD | Фактический выход |
|---|---|
| Контроль: `system=Standart, sub_type=vertical` | `ok=true`, 12 направляющих, 48 кронштейнов, 60 кляммеров |
| `system="NordFOX"` | Явный отказ, 0 элементов |
| `system={"name":"NordFOX"}` | `ok=true`, имя NordFOX в `system_used`, 12 направляющих, 0 кронштейнов, 60 кляммеров |
| `system=Standart, sub_type=nordfox` | Успех; геометрия полностью совпадает с вертикальным контролем |
| Расчётный контроль `sub_type=vertical` | Успех; 36 рядовых интервалов проверены |
| Тот же расчёт с `sub_type=nordfox` | Успех; та же геометрия, `scheme=vertical`, но `layout_verification.passed=true` при 0 проверенных интервалов в обеих зонах |
| `calc.scheme=nordfox` | Явный отказ |

Причины: [frame_plan.py](../../AFrame/engine/frame_plan.py):232–238
допускает неизвестное имя словаря как пустую базу; строковое имя проверяется
на 239–240. `sub_type` на 1280 не проверяется по перечислению. При этом
проверка интервалов на 1004–1011 для любого значения, кроме `vertical`,
выбирает горизонтальные элементы. Неизвестный тип может получить вертикальную
геометрию и пустую выборку проверяемых интервалов.

Эти входы недоступны из штатного списка схем формы. Дефект находится в API,
а не в обещании поддержки NordFOX. Создание пользовательской системы
полным словарём может быть намеренной возможностью; проблема - успешное
принятие неполного неизвестного пресета без явной проверки обязательных правил.

Повтор baseline:

```bash
python3 tools/atr_review_3009/nordfox_contract_probe.py --revision 5cdd34e \
  --output /tmp/nordfox-contract-baseline.json
```

Скрипт фиксирует семь сценариев и восемь наблюдений. `true` в observations
означает воспроизведение поведения, включая ошибки, а не приёмку расчёта.

**Параллельные изменения:** при дополнительном запуске на изменяемом рабочем
дереве расчётный неизвестный `sub_type` уже отклонялся проверкой соответствия
схемы подсистеме. Это не меняет доказательство для базового HEAD; текущую
приёмку исправлений выполняет общий набор регрессий. Неизвестное имя-словарь
и ручной неизвестный тип нужно проверять отдельно. Продукт этот агент
не исправлял.

## Нерешённые проектные параметры и состав результата

Перед реализацией NordFOX требуется согласованная серия/редакция и способ
крепления облицовки. По самому альбому остаются проектными: допустимый формат
и толщина, шаги опор, размеры пролётов/консолей, сечения и исполнения,
число промежуточных кассетных профилей, схема крепления/анкеры по испытаниям,
вылеты/удлинители, швы и температурные перемещения, узлы проёмов и пожарные
решения. Общее число опор не заменяет эти данные.

Лист 18 перечисляет полный состав рабочей документации: пояснительная часть,
спецификация, контур работ, раскладки облицовки с узлами, кронштейнов,
направляющих и креплений, сами узлы, статический расчёт, испытания анкеров,
инструкции по монтажу и эксплуатации. AFrame выдаёт часть геометрической
схемы и расчётную цепочку другой системы; его результат не равен такому
комплекту NordFOX.

## Современный публичный источник

[Текущая карточка производителя](https://nordfox.ru/systems/system-5/)
проверена 30.09.2026. В ней указаны алюминиевые сплавы 6060/6063,
керамика 3–6 мм и формат до 3500×1500 мм; техническая документация доступна
по запросу. Эти данные не смешивались с АТР 2016. Самой карточки недостаточно
для переноса старых узлов в современную проверенную комплектацию.

Рекомендуемый порядок дальнейшей работы: сохранить NordFOX как отдельную
неподдержанную систему в каталоге происхождения правил; согласовать редакцию
и набор сборок; описать связи и fixed/sliding на уровне узлов; затем
создать и проверить отдельную расчётную/геометрическую реализацию.
Изменять общие правила Вектора по этому альбому оснований нет.
