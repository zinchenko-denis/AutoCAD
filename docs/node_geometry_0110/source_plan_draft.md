## Что пока не определено

1. Интервал монтажного перемещения и минимальный/максимальный перехлёст КР2–УК выбранного узла.
2. Полная размерная цепочка от строительного основания через прокладку, КР2, УК и ГП до наружной поверхности плиты. Эскиз не заменяет численного монтажного контракта.
3. Координаты и допуски отверстий, радиусы гиба, форма выштамповок, точные посадки.
4. Толщина выбранной облицовки, положение и толщина кляммера, расстояние между облицовкой и полкой ГП. Они не следуют из общего выноса.
5. Наружная фактическая плоскость мембраны, если она отличается от суммы толщин утеплителя. В 2Б2 хранится только сумма заявленных слоёв; пустой список означает отсутствие декларации, а не гарантированный нулевой слой.
6. Неподвижные/подвижные соединения, усилия, анкеровка, непрерывность стыков, подтверждённые сечения. Геометрическая схема не закрывает эти данные.

## Воспроизведение конкретного пробела

`baseline.json` получен вызовом действующего `frame_plan` на синтетическом контуре 1200 × 2400 мм. Для выноса наружной облицовки 180 мм и слоёв 150 + 50 мм движок возвращает `ok=true`, 2 направляющие и 8 кронштейнов; отдельного узлового разреза/проверки зазора нет. Два других случая (230 / [100,50] и 230 / [150,50]) дают ту же плановую геометрию. Это ожидаемое ограничение декларативного контракта 2Б1/2Б2, а не вновь открытая старая ошибка: отчёт честно содержит `existing_preset_only`.

Новый этап должен построить отдельный проверяемый результат геометрии, а не молча изменить смысл уже сохранённых деклараций. Числа примера синтетические, не рекомендуемые проектные значения.

## Рекомендуемый минимальный инкремент

Сначала выполнить **размерную схему слоёв и базовых плоскостей одного узла**. Исходные декларации берутся из актуального разрешённого выбора проекта/зоны. Вводим явно подписанную плоскость основания x = 0 и направление наружу. Толщины слоёв задают их последовательные границы; вынос задаёт только плоскость наружной облицовки. Элементы с неизвестным положением не размещаются по догадке.

Для проверки локального min20 нужен отдельный явный ввод положения ближайшей поверхности ГП относительно основания и определение наружной поверхности мембраны/утеплителя. Не подменять его выносом облицовки или расчётным плечом. При таких вводах простая размерная проверка вычисляет `x_ГП − x_наружная_поверхность_утеплителя_или_мембраны`. Источник координаты — проектная декларация, а источник минимального значения — конкретный лист 4.2.1. Результат — «локальный просвет по заявленным плоскостям», без общей оценки годности узла.

Если новых положений пока нет, полезный результат всё равно возможен: показать известные слои и вынос, перечислить незамкнутую размерную цепочку, вывести точный статус «недостаточно данных для локального просвета и подбора». Случай, когда утеплитель уже выходит за наружную облицовку, должен давать понятное противоречие исходных плоскостей, а не зелёную схему.

Полное тело кронштейна/удлинителя, отверстия и крепёж, автоматическая длина и нативный динамический DWG-блок с ручками не входят в первый инкремент. Следующее размещение деталей требует монтажного контракта. Нельзя иллюстративным эскизом присвоить сборке статус рабочего чертежа.

## Архитектура и скорость

- Чистая функция получает один неизменяемый DTO уже разрешённого выбора и локальные геометрические вводы. Никаких чтений AutoCAD/файлов/каталогов внутри вычисления.
- Один общий результат на уникальную комбинацию геометрических входов; привязки к зонам отдельно. Не копировать полный контекст всех зон в каждый узел.
- Размерные цепочки линейны по числу слоёв; количество примитивов ограничено. Не выполнять расчёт на каждую направляющую/кронштейн всей раскладки.
- Новая пользовательская операция читает только выбранную каноническую зону и проект; перед записью повторяет существующую проверку актуальности. Полного обхода DWG и тяжёлого реактора нет.
- Сохранённая схема получает версии входов, источник и инженерный статус. Изменение проекта делает результат устаревшим без автоматической регенерации всего чертежа.
- Сохранять отдельно время чистого расчёта, чтения CAD и вставки; синтетическое время не обещает время живого DWG.

## Адресная проверка

Границы 19,999 / 20 / 20,001 мм для локального просвета при явно заданных плоскостях; отсутствие положения профиля; пустой список слоёв; противоречие утеплителя и наружной облицовки; разные происхождения одинакового итога; нет молчаливого переноса min30; неизвестное сечение не разрешает статику; изменение проекта между просмотром и записью; отмена без записи; отдельные измерения для 1/100/1000 зон, линейный объём DTO. Живая AutoCAD-проверка остаётся необходимой после ревизии и завершения правок.
