# Протокол фасадного пилота — форма для проектного отдела

Заполнить по [PILOT_GUIDE.md](PILOT_GUIDE.md). Один протокол — одна машина
и один согласованный выпуск. Исходное состояние всех пунктов — **NOT_RUN**.
Целевой выпуск — **build-105**, SHA `c4009838875aa0f225971153bf4b54fe288e8e79`.
Фактически установленную версию всё равно записать в паспорте ниже.
Правильный предусмотренный отказ отмечается PASS, а не ошибкой пользователя.
Монтаж 2В, расчёт 3А и полный состав крепежа этим протоколом не принимаются.

и новое обоснованное ожидание, а не сравнивать с чужим эталоном.
