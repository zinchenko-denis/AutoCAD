# Установка фасадных модулей в AutoCAD 2024

Проверочный выпуск build-105 для Германа и проектного отдела. Устанавливается на полный AutoCAD для Windows 64 bit. Версия 2024 у Германа подтверждена журналом проекта. AutoCAD LT, Mac и 2025+ этим комплектом не заявлены.

## Какие файлы скачать

Откройте [выпуск build-105](https://github.com/zinchenko-denis/AutoCAD/releases/tag/build-105). В разделе Assets скачайте именно три архива:

- `AFacades.bundle.zip` — зоны, площади и ведомости.
- `AClad.bundle.zip` — раскладка облицовки.
- `AFrame.bundle.zip` — каркас, параметры проекта и схема узла.

Скачивать `Source code` для установки не нужно. Все три архива должны быть из build-105. Прежние ATableSpec и ABlockGen оставьте установленными как есть: они не участвуют в этом фасадном пилоте. Отдельные Python, .NET SDK и средства разработки не требуются; Python включён в EXE. Плагины используют .NET Framework 4.8 штатной среды AutoCAD 2024.

## Установка и обновление

1. Закройте все окна AutoCAD. Сохраните копию рабочего DWG и соответствующего файла `_fzones.json`.
2. Для каждого скачанного ZIP откройте «Свойства». Если Windows показывает «Разблокировать», отметьте его и нажмите «Применить» до распаковки.
3. Распакуйте ZIP. В каждом архиве должна получиться одна папка с окончанием `.bundle`.
4. Вставьте в адресную строку Проводника `%APPDATA%\Autodesk\ApplicationPlugins\` и нажмите Enter.
5. При обновлении перенесите старые папки AFacades.bundle, AClad.bundle и AFrame.bundle в резервную папку **вне ApplicationPlugins**. Поместите вместо них новые три папки целиком. Не смешивайте старые DLL с новыми EXE и не оставляйте дубли модулей под другими именами.
6. Проверьте структуру: например, `ApplicationPlugins\AFrame.bundle\PackageContents.xml`, а ниже `Contents\net48\AFramePlugin.dll` и `Contents\engine\frame_engine.exe`. Между ApplicationPlugins и AFrame.bundle не должно быть лишнего уровня распаковки.
7. Запустите AutoCAD. При запросе доверия проверьте путь и разрешите загрузку файлов этого комплекта. Глобальную защиту загрузки не отключайте.

## Проверка установки

Нажмите F2 и сохраните строки загрузки AFacades, AClad и AFrame. Для точной версии откройте `Contents\net48\build-info.json` в каждой из трёх папок: везде должно быть `build: 105`, `sha: c4009838875aa0f225971153bf4b54fe288e8e79`.

На пустом сохранённом учебном DWG проверьте вызов `ATFPROJECT`, затем `ATFZONE`. Окно должно открываться; для проверки установки достаточно закрыть его кнопкой «Отмена». Команды `ATTILE`, `ATFRAME`, `ATFNODE` и `ATFTABLE` проверяйте далее по маршруту пилота: некоторые требуют уже созданную зону или другие данные.

Если команда неизвестна, проверьте три папки, `PackageContents.xml`, DLL и EXE, версию AutoCAD и сообщение доверия. Если защита Windows или организации блокирует файл, передайте точный текст администратору; не отключайте антивирус. Если нужен доверенный путь, администратор добавляет только каталог проверенного комплекта, сохраняя защиту остальных каталогов.

## Первый проход и откат

Начните с учебного примера по `PILOT_GUIDE.md` или его версии Word. Затем используйте копию небольшого реального фасада. Расчёт несущей способности и автоматический подбор пилота не завершены; ручное построение, ведомости и диагностическую схему можно проверять независимо от них.

Для возврата к прежнему выпуску закройте AutoCAD, уберите новые три папки и верните резервные папки целиком. Восстановите также контрольную **пару DWG и JSON**, если откатываете результаты работы. Не считайте совместимость новых служебных записей со старой DLL проверенной.

При проблеме передайте номер build, версию AutoCAD из «О программе», три строки загрузки, текст F2, команду и последний шаг. Для ошибки геометрии приложите учебный либо разрешённый к передаче DWG вместе с его JSON.
