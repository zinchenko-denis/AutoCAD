# Руководство начинающего пользователя фасадных модулей

Откройте **[Facades_Beginner_Manual_30.09.docx](Facades_Beginner_Manual_30.09.docx)**. В руководстве31 страница,20 глав и10 схем: от первого запуска AutoCAD и подготовки контуров до зон, раскладки, подсистемы, ведомостей и исправления типовых ошибок.

Сначала прочитайте раздел «Какой версией пользоваться». Исправленные исходники зафиксированы в коммите `8360c23`, но соответствующий установочный выпуск ещё не опубликован. Старый комплект не гарантирует все описанные команды и исправления. Обновлять AFacades, AClad и AFrame необходимо вместе.

## Учебные файлы

| Файл | Для чего |
|---|---|
| [01_source_rect.dxf](assets/01_source_rect.dxf) | Первое упражнение: стена6000×6000 мм и два окна |
| [02_source_gable.dxf](assets/02_source_gable.dxf) | Второе упражнение: фронтон со скатами |
| [03_reference_rect.dxf](assets/03_reference_rect.dxf) | Геометрический результат прямоугольного примера для сравнения |
| [04_reference_gable.dxf](assets/04_reference_gable.dxf) | Геометрический результат облицовки фронтона для сравнения |

Скопируйте исходные DXF в свою учебную папку. Откройте в AutoCAD и сохраните как DWG. Выполняйте команды по руководству; файлы `reference` открывайте отдельно для сравнения. Они не содержат служебных меток плагинов, поэтому не служат готовыми проектами для повторного расчёта. Элементы подсистемы в учебном примере заданы ручными шагами и не являются монтажным решением.

Изображения — учебные схемы из ответов движков, а карты полей — схемы текущего интерфейса. Это не снимки работающего AutoCAD. Происхождение и техническая проверка описаны в [SOURCES_AND_QA.md](SOURCES_AND_QA.md).

## Для продолжения разработки

- `manual_content.md` — редактируемый текст.
- `generator.py` — генерация десяти изображений, четырёх DXF, запросов/ответов и проверок геометрии; нужны matplotlib, Shapely и ezdxf. Продуктовые движки остаются без этих зависимостей.
- `build_manual.py` — сборка Word через python-docx и Pillow. После изменения текста или изображений нужно заново собрать документ, отрендерить и проверить каждую страницу.
- `SOURCE_COMMIT.json` связывает итоговый Word с коммитом продукта и проверенными хешами исходников. `assets/source_manifest.json` сохраняет исходные данные на момент генерации.

Регенерация выполняется из корня репозитория:

```bash
python docs/facades_beginner_3009/generator.py
python docs/facades_beginner_3009/build_manual.py
```

Состояние исправлений и живые проверки, которые предстоит провести в AutoCAD, перечислены в [FIXES_30.09.md](../FIXES_30.09.md).
