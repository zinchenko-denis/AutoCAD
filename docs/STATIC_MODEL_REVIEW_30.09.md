## Подтверждённая проблема

Первичные расчёты задают непрерывную направляющую с условно неподвижной и подвижными опорами. Геометрические пересечения НСП с НГП, отметки перекрытий и символ вставки не устанавливают такой расчётный контракт. Размер зазора, в том числе нулевой, сам по себе не подтверждает передачу момента через стык.

Независимый синтетический пример: цельный НСП 6000 мм, три НГП на отметках 0/3000/6000, два пролёта. Старая программа выдала положительный результат по многопролётной строке. На фактическом угловом интервале 192,8572 мм напряжение составило 2167,8 при пределе 2250 кг/см². Диагностическая подстановка уже существующей двухпролётной строки при тех же входах дала 2554,4 кг/см². Это проверка чувствительности прежнего алгоритма, **не новая утверждённая расчётная модель**.

Более простой воспроизводимый пример на штатной длине НСП и его численная проверка, а также точные страницы первичных источников приведены в [Source_findings.md](static_review_3009/Source_findings.md). Скрипт [reproduce_model_gap.py](../tools/static_review_3009/reproduce_model_gap.py) запускает исходный код из Git и текущий код. Приватные оригиналы и реквизиты проектов в отчёт не перенесены.

Для вертикальной схемы контур 1200×140 мм выдавал куски с одной опорой, а для ортогональной — без пересечения с горизонтальной направляющей. При этом проверка расстояний возвращала `passed=true` с нулём интервалов. Дополнительно выявлены однопролётные куски, подменяемые минимум двумя пролётами, и выбор коэффициентов по условной длине вместо фактического количества опор отдельного куска.

## Изменение поведения

| Случай | Поведение |
|---|---|
| Расчётная межэтажная схема | Отказ `E_CALC_MODEL_UNCONFIRMED`: не подтверждены соединения и непрерывность; новый положительный расчёт каркаса не выдаётся. Ранние адресные отказы по неподтверждённому сечению, свободным концам и несовместимой схеме сохранены. |
| Межэтажная в окне AutoCAD | Раннее объяснение ограничения. Автоматического переключения на ручные шаги нет. |
| Ручная межэтажная геометрия | Сохранена; шаги и узлы должны следовать отдельному проектному расчёту. |
| Вертикальная/ортогональная: менее двух опор | Отказ `E_CALC_TOPOLOGY_UNSUPPORTED`; ноль проверенных интервалов не считается положительной проверкой. |
| Две опоры, один пролёт | Отказ: в текущей цепочке отсутствует подтверждённая однопролётная модель. |
| Фактический класс пролётов расходится с применённой строкой коэффициентов | Адресный отказ с перечнем кусков и опор. Новый коэффициент автоматически не назначается. |
| Остальные расчётные вертикальная/ортогональная | Ограниченная арифметическая цепочка и геометрический контроль. `static_model.status=not_verified`: полная применимость статической модели не подтверждена. |

Геометрический анализ вынесен в `AFrame/engine/frame_topology.py`. Он описывает каждый выданный кусок отдельно и не склеивает стойки через зазоры. Неподвижное/подвижное закрепление не угадывается по словам «несущий»/«рядовой». Через CLI передаются диагностика и идентификатор отказавшей зоны; при отказе геометрия всего запуска отсутствует. Прежняя схема в DWG сохраняется существующим порядком команды: ответ движка проверяется до удаления.

Численные формулы и характеристики сечений `frame_calc` не изменены. Их прежние эталоны остаются проверкой воспроизведения арифметики источников. Правило «достаточно четырёх пролётов» не введено: первичный рисунок условный, а число пересечений не заменяет модель закреплений и стыков.

## Что остаётся открытым

1. Полный контракт опор: какие перемещения и повороты разрешены, какие усилия передаются в каждом узле, на какой элемент относится опора.
2. Реальная непрерывность направляющих и работа стыков; распределение веса между неподвижными опорами. Расчётный участок не равен всему набору соосных отрезков.
3. Применимость коэффициентов к неравным пролётам, свободным концам и фактической схеме vertical/ortho. Успешный геометрический контроль этого не доказывает.
4. Расчёт горизонтальных НГП/СП и соединений, затем общий расчёт каркаса по подтверждённым узлам. Нельзя замыкать цепочку только заменой одного коэффициента.
5. Живая проверка AutoCAD после завершения правок и ревизии: перегенерация, отмена, сохранение прежнего результата при отказе, метаданные, Undo/SaveAs и динамические блоки.

Прежние ограничения сохранены: тип 5 и NordFOX не реализованы; АТР Вектор-4 отсутствует; НСП-2 и ГП-60-40 ограничены в расчёте до подтверждения сечений; АКП — каркас без узла крепления кассеты. Числа отдельных проектов не стали универсальными пределами.
