# Ответ на независимый разбор AutoCAD от 23.09 — фасадная часть

**Дата: 24.09.2026. Ветка `feat/auto-reactor`, исправления — коммиты `1436e6d` … `8489433`
(поверх проверенного рецензентом `aa47a78`). Сборка не выпускалась — ждём живой приёмки.**

Спасибо за разбор: он точный и полезный. По решению заказчика в этот заход
работали только с фасадной частью (ATFZONE, ATTILE/ATCLAD, ATFRAME) и с
выпуском. Замечания по ATableSpec и ABlockGen (модули другого конструктора)
не оспариваем — они отложены решением заказчика, код этих модулей не менялся.

## Как проверяли

- Каждое замечание сначала **воспроизведено на `aa47a78`** тем же входом, что у
  рецензента (Python-движки — прямым прогоном; пути C# — разбором кода, как и у
  рецензента). Воспроизвелись все проверенные фасадные замечания.
- На каждое исправление — регрессионный тест; новые тесты **падают на старом
  движке** (негативный контроль): Facades — 8 из 11, остальные — позитивные
  охранные случаи.
- Штатные прогоны после исправлений: Facades 50 + 22 юнита (было 39 + 22);
  AClad 173 + 12 + 58, краш-аудит 124/0; AFrame 162 + 79 + 8 (было 151),
  краш-аудит 181/0; сверка с полигоном инженера — **без изменений**; фикстура
  290×82 — **145 333** плитки; синтетика: зоны 840/2 419 — нарушений нет;
  раскладка 741 сценарий / 376 086 кусков — 0; подсистема 3 × 600 — только
  известные открытые вопросы (см. ниже).
- C# (AutoCAD) компилируется в CI на Windows против сборок AutoCAD: check
  #165–#169. **В живом AutoCAD изменения ещё не прогонялись** — это
  следующий шаг (матрица ниже).

## Что осталось и предлагаемый порядок

1. **Живая приёмка в AutoCAD** на копиях рабочих DWG:
   - повторный ATFZONE, совпадающие обводки, изменение числа частей объединения, копирование зоны, Undo, SaveAs/перенос DWG, отмена в каждом диалоге;
   - ATTILE/ATFRAME: одна из нескольких зон отказала, выбор части общей раскладки, COPY → повтор на копии, переход ATCLAD ↔ ATTILE, «только кляммеры»;
   - ATDEDUP: Esc, Enter, «Нет», Undo; динамические профили разной длины;
   - меню «Фасады»: запуск → выход → отмена выхода.
2. **Геометрия зоны — в DWG** (метка зоны хранит facade_zone/1; `_fzones.json` — экспорт), отпечаток формы для проверки свежести; миграция старых чертежей.
3. **Расчёт по участкам стоек** с независимой инженерной приёмкой: грузовые полосы каждой стойки, финальная проверка выданной схемы.
4. **Роль стойки в метке ATFRAME** — чтобы «только кляммеры» повторял полную раскладку точно.
5. **Правила инженера:** опирание кусков вертикали ортогональной; частичная кромка; допустимы ли перекрытия зон разных материалов; кляммеры при разбежке — по локальным стыкам или по осям.
