# Независимый геометрический эталон ограниченного пилота П1/П5

Дата: 01.10.2026. Основа проверки: `b64eb0aedccb41ba5cb1e253c9eddf69142284b3`.
Статус: арифметика и координаты сверены с предварительным engine-прогоном;
стабильная сквозная цепь и её выдача **AWAIT_STABLE_REVIEW**, живой AutoCAD
**NOT_RUN**. Это контроль количеств учебного стенда того же пилота, не монтажный
проект и не положительный расчёт несущей способности.

## Происхождение и граница независимости

Точный вход из двух прямоугольников 1210×1820 мм составлен для этой приёмки.
Он не выдаётся за неизменённый старый fixture или за геометрию реального объекта.
Использован существующий учебный модуль 600×600 / шов 10 мм из
`AClad/engine/test_cladding_plan.py`, C1–C3. Принцип передачи фактических осей
ATTILE→ATFRAME уже проверяется в `AClad/engine/test_tile_pattern.py`, T27
(там другой шов и другой размер стены). Старый бетонный пример руководства
6000×6000 с окнами не превращён в пилот керамогранита сменой подписи.
Новых альбомов и характеристик здесь нет.

Формулы плит и площадей ниже получены из размеров, без вызова продуктового
алгоритма. Координаты кронштейнов — независимое применение уже существующего
программного правила `frame_plan._rail_brackets(..., exact=True)` с ручным
шагом 800 и крайними отступами 300. Оно проверяется как поведение геометрии;
его применимость к монтажу этого стенда не утверждается. Проверка схемы по
координатам выполнена также визуально на отдельном построении из эталона,
не на снимке AutoCAD.

## Фиксированный вход

Все координаты в мм, плоскость XY, проёмов и общих границ нет.

| Контур исходного входа | Вершины | Положение | ID из предварительного ATFZONE engine |
|---|---|---|---|
| `1` | (0,0), (1210,0), (1210,1820), (0,1820) | Левая стена | `П-2` |
| `2` | (2410,0), (3620,0), (3620,1820), (2410,1820) | Правая стена | `П-1` |

Присвоенный zone ID нельзя связывать с позицией в массиве или порядком
исходного выбора. Для этого зафиксированного ответа соответствие установлено
по `outer_contour_id`/`outer_id`, вершинам и bbox. В живом DWG реальные ID
записывают после команды; геометрический эталон не требует конкретного
номера марки справа.

ATFZONE: две отдельные зоны, объединение выключено. ATTILE: керамогранит
600×600, оба шва 10, ряды, без смещения, привязка слева-снизу к bbox,
`gap_around=false`, `merge_touching=false`, фигурные сохранять; min_piece 10,
warn_cut 30, kerf 3. В стабильном сценарии каждая зона проходит отдельную
операцию ATTILE и ATFRAME в одном документе.

ATFRAME: вертикальная, керамогранит, только каркас, ручной рядовой и угловой
шаг 800, крайний отступ 300; дополнительных углов/перекрытий нет. Оси взяты
из раскладки. Штатный `FrameSettings` порождает `exact_step=true`,
`floor_step=0`, `parts=frame`; искусственный `rail_std` не добавляется.

Исторический выбор: Вектор-1 2015, тип 1, узел 4.2.1; КР2 оцинкованный с
окраской, ширина 70, L200; УК такое же исполнение, ширина 70, L100, c1.2;
ГП a40, b40, c1.2, b/c заявлены по проекту. Это допустимое заявление через
обычные Settings, а не назначение изделий физическим деталям. Для выбранного
решения `FrameSettings.ValidateSolutionSelection` требует вертикальную
схему, керамогранит и ручной режим. Автоподбор остаётся закрыт.

## Точные ожидания

Для каждой стены: `1210 = 2×600 + 10`; `1820 = 3×600 + 2×10`.
Начала плит по местным координатам: X={0,610}, Y={0,610,1220}; 2×3=6 целых.
Глобальный X правой стены получается прибавлением 2410.

| Величина | Одна зона | Обе зоны | Независимая формула |
|---|---:|---:|---|
| Число зон | 1 | 2 | Два непересекающихся замкнутых контура |
| Чистая площадь зоны, м² | 2.2022 | 4.4044 | 1210×1820/10⁶; проёмов нет |
| Наружный периметр, м | 6.06 | 12.12 | 2×(1210+1820)/1000 |
| Целые плиты | 6 | 12 | 2 столбца × 3 ряда |
| Подрезки / фигурные / малые | 0 | 0 | Каждый прямоугольник целиком внутри стены |
| Площадь установленных плит, м² | 2.16 | 4.32 | 6×600×600/10⁶ |
| Площадь швов, м² | 0.0422 | 0.0844 | (10×1820+2×10×1210−2×10×10)/10⁶ |
| Заготовки плит без запаса | 6 | 12 | Подрезок нет; пропил не используется |
| Отход плит в этом задании | 0 | 0 | Площадь швов не является отходом |
| Вертикальные ГП, шт. | 1 | 2 | Одна сквозная вертикальная ось стыка на стену |
| Сумма длин ГП, м | 1.82 | 3.64 | 1820/1000 на стену |
| Геометрические кронштейны, шт. | 3 | 6 | Y={300,1100,1520} |
| Горизонтальные профили / кляммеры / fittings | 0 | 0 | Выбран режим только каркаса |
| Геометрические кандидаты bracket–rail | 3 | 6 | Три совпадения на каждом отдельном ГП |
| Геометрические стыки отдельных ГП | 0 | 0 | По одному целому куску на стену |

Вертикальные оси: X=605 слева, X=3015 справа; горизонтальные оси швов
Y={605,1215}. ГП: Y=0…1820. Для кронштейнов нижняя граница ряда 300,
верхняя `1820−300=1520`; следующий после 300 равен `300+800=1100`, а
следующий 1900 выше 1520, поэтому последний ставится в 1520. Интервалы
800 и 420, геометрические свободные концы 300/300. Число два между тремя
кандидатными опорами не подтверждает двухпролётную расчётную модель.

Количества физического producer, таблиц и XLSX должны быть сверены с этим
эталоном стабильным аудитом. Число строк ведомости, группировок или оценка
хлыстов не заменяют 2 установленных ГП / 3.64 м. Закупочную спецификацию,
схему раскроя ГП и комплект метизов эталон не задаёт. Физический УК не
представлен: ожидается отсутствие его фиктивного добавления, а не вывод,
что при монтаже требуется ноль УК. `product_id=null`,
`physical_assignment=not_asserted` сохраняются.

## Локальный просвет и изменение параметров

Стабильному сценарию заданы учебные декларации из главы 13 существующего
руководства: слои [100,50] → границы 0/100/150; явно выбрана наружная граница
слоёв 150; ближайшая к стене поверхность ГП 170; наружная облицовка 230.
Ожидаемый локальный просвет `170−150=20 мм`. При 169.999 ожидается
`19.999<20`, вставка должна отказать без округления до допуска.
Пустая/неподтверждённая поверхность не получает автоматического значения 150.

Последовательность стабильного сценария: общая наружная плоскость 230→240;
после повторной выдачи — местное исключение правой зоны 260. В итоге слева
240, справа 260; поверхности 150 и 170 неизменны, поэтому просвет остаётся
20 и все количества этой таблицы остаются прежними. Различающиеся итоговые
решения обрабатываются отдельными операциями. Изменение проекта делает
зависимые снимки неактуальными, даже при неизменных физических количествах.
Проверка этой зависимости и отсутствие дубликатов — задача стабильной цепи,
не следствие одной арифметики.

В предварительном `p1p5_recon/frame_request.json` ещё были пустые слои и
не заданная наружная облицовка: тот прогон подтверждает координаты каркаса,
но не выполнение команд проекта/узла. Нельзя приписывать ему проверку 20 мм.
Локальное правило 20 мм унаследовано из проверенного узла 4.2.1, PDF20,
SHA256 `7386f4152de455a5e2622704d51a98d8f05afd20050807f634eea4572de37142`;
повторной полной ревизии PDF в этой итерации не было.

## Что остаётся открытым

Монтажный допуск 2В/расчёт 3А — **BLOCKED**: нет доказанного назначения
физических КР2/УК/ГП и двух интерфейсов ГП–УК/УК–КР2, отверстий/метизов,
перемещений/поворотов, температурного хода, пути веса и работы стыка.
Проверка количества и просвета эти факты не выводит. Номинальные базы 2Б5
сохраняются: стена 0, ПП2, свободный торец КР2 `2+L`; пятка УК
`2+LКР2+LУК−h`, h не подтверждён. Для L200/L100 это `302−h`, не готовый вынос.

Живые DWG, реальные формы/выбор объектов, Undo, сохранение/открытие,
COPY/SaveAs, CAD-транзакции и производительность AutoCAD этим чтением не
проверены. Для них подготовлен `human_acceptance.md`; выполнение не отмечено.
Первичные входы/хеши и машиночитаемые ожидания — `independent_oracle.json`.
