## Исправление регрессии выпуска №106

Третий круг независимой ревизии принят после воспроизведения на
`1f474ca79266f3ec6ff0a735dc50ddd671ac56a2`; удалённая ветка совпадала,
локальных изменений не было. **Запрет всего фасада из-за исходного
короткого куска противоречил ответу Германа от 07.08.** Это регрессия
предыдущего исправления, а не отсутствие нового инженерного задания.

| Замечание | Изменение для конструктора |
|---|---|
| Короткий участок блокирует ручной режим | Восстановлено прежнее правило: один кронштейн по центру при длине до двух торцевых отступов включительно (600 мм при старте 300). Участок строится и получает красную пометку. |
| Локальный непройденный расчёт снимает весь фасад | Геометрия сохраняется; конкретные непроверенные или перегруженные куски отмечаются. Итог `partial` и отрицательные проверки сохраняются; построение не называется успешным расчётом. |
| Пометку можно потерять после команды | Список с зоной, координатами и причиной доступен в F2 и ATFTABLE → Подсистема, включая Excel. Сохраняется при записи и повторном обновлении кляммеров. Кружки у блоков — служебные, не материал ведомости. |
| Зелёные тесты допускают бесполезный отказ | Пять типовых фасадов обязаны строиться в обоих режимах. Проверяются каждый отмеченный кусок и сохранение заданных отступов; пустой результат или общий отказ — FAIL. |
| Прогиб свеса a/150 против a/75 | Сравнение ревизора верно, но a/75 для направляющей не подтверждён применяемой расчётной цепочкой. Число не изменено; консервативный критерий программы обозначен явно. Причина и первичные источники — в разборе ревизии. |

хлыстов сохранено. Некорректный ввод и неподдержанные глобальные схемы

для восстановления ручной расстановки не требуется: ответ уже есть в истории.

Прежние исправления сохранены: расчёт по фактическим пролётам/свесам,
ATFZONEACCEPT для старых зон, проверка версий трёх модулей, новые кнопки
