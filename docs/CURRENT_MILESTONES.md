## История передачи 06.10: проверка программы и библиотека параметрических узлов

Денис уточнил цель по комментарию Германа и **разрешил следующий участок
разработки**: проверить существующий путь с учётом регрессий, затем сделать
один настоящий параметрический узел одной подсистемы. Это изменение задачи
отменяет прежнее «новые функции пока не начинать» только для этого пилота.
Массовое расширение библиотеки — после проверки первого примера.

**Потребность Германа:** отдельный DWG с библиотекой типовых узлов из
альбомов. Инженер задаёт параметры проекта (утеплитель, вынос, выбранные
кронштейны и профили), выбирает рамкой нужные экземпляры и получает
согласованное изменение их геометрии, размеров и марок. Остальные узлы
не меняются. В дальнейшем — вертикальная, межэтажная и ортогональная
системы, примыкания и отливы; развёртки фасонных деталей при наличии
необходимых исходных данных. Это **не** справочная схема слоёв ATFNODE.

Первый результат: один библиотечный DWG и один настоящий динамический
узел, предпочтительно уже изученный Вектор-1 2015 / тип 1 / 4.2.1.
Сценарий приёмки: пять вставок, выбрать три, изменить параметры, проверить
геометрию/размеры/марки выбранных и неизменность двух остальных. Нужны
