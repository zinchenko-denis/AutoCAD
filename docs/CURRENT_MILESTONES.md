## Что именно мешает критическому пути

- Исторический выбор КР2/УК/ГП не назначает изделия фактическим экземплярам.
  В текущей физической модели нет отдельного УК и двух подтверждённых интерфейсов.
- Базы `0 / 2 / 2+L` и формула положения УК содержат неизвестный `h`.
  Полный диапазон, посадка и применимость крепежа не установлены.
- Идеализированные опоры и грузовая длина расчётного примера не сопоставлены
  реальным связям каждого элемента. Соседство направляющих не доказывает
  передачу усилий через стык.
- Две проверки заклёпок в расчётном примере не задают универсальный комплект
  для всех фактических опор.

Не требуется заранее решать все системы или весь диапазон регулировки:
для ограниченного расчёта достаточно одного доказанного монтажного варианта
и применимой упрощённой расчётной модели. Имеющиеся доказательства пока
не задают однозначно и такой вариант. Подтверждённый расчёт одного фиксированного
варианта сам по себе не разрешает автоподбор по всему диапазону.

На прежних источниках нового основания для завершения 2В/3А не найдено.
Новые альбомы не привлекались. Программирование дополнительных UK ID,
коэффициентов или разрешающего флажка не заменит этого основания.

## Правило остановки и отчётности

После конечного сценария N1/N2 и обязательных проверок **не назначать
автоматически новый адаптерный этап**. Save/open, Undo и native remapping
остаются конечным списком для настоящего AutoCAD. Новая работа над
доказанной инженерной границей начинается только при конкретной новой
гипотезе или подтверждённом факте; повтор прежнего отказа не становится вехой.

Каждый отчёт сессии начинается четырьмя пунктами:

1. Пункт исходного плана и его состояние до работы.
2. Что изменилось для пользователя: функция, исправление либо только проверка.
3. Что действительно закрыто и что осталось.
4. Следующее действие и его конечный критерий.

SHA, CI, число проверок и замеры идут как доказательства результата.
Не объявлять проценты или число оставшихся сессий без основания.

Скорость сохраняется критерием: один проверенный снимок на фазу,
индексы вместо поиска для каждой детали, без пересчёта/обхода из реактора.
ATableSpec, ABlockGen и main не менять. Монтаж/расчёт/автоподбор закрыты
до достаточного основания; установочный выпуск — только по «Собираем».
