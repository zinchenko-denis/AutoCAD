# Независимая проверка 2В2

Проверка локального кода — **PASS**, открытых продуктовых блокеров нет.
База: `1a6066d541ed2f62ac40809e1a87e09e434ab591`. Точный diff и SHA256
перечислены в `independent_review.json` и `independent_reviewed_change.patch`.

Проверены generated origin, исходный `source_run_id`, одна каноническая
выбранная зона, retained/duplicate паспорта и текущие физические элементы.
Многозонный элемент, чужой прогон, unavailable/legacy/manual источник не
дают ложного отрицательного вывода. Полные ссылки собираются до дедупликации
строк; прежняя диагностика общих кандидатов 2В1 сохранена.

При ревизии найдены и закрыты два дефекта. Разный порядок допустимых
alias-паспортов раньше давал ложный orphan; исходная независимая проба
теперь даёт ноль в обоих порядках. Объединение длинных ID и зоны создавало
единственную новую ячейку на 33201 символ при baseline-максимуме 20127.
На том же неизменённом входе нумерованные продолжения теперь не превышают
8000, полный ID и зона восстанавливаются без потерь, XLSX roundtrip точен.
Новый постоянный тест также проверяет Unicode. Это синтетические границы
валидатора, а не утверждение о нормальном producer GUID или живом CAD.

Фактически повторены orphan: **2577 PASS / 72 XLSX**, прежние 2В1:
**35 + 71 + 8781 проверок, 50 XLSX PASS**. Дополнительные индексы линейны
по элементам, областям паспортов и ссылкам; продолжения линейны по длине
выводимого текста. Новых чтений CAD, поиска геометрии и перестроения нет.
Исходные DTO и инженерные статусы не меняются.

UI с обоими реальными fixture компилируется. Локальное исполнение
**BLOCKED: Xvfb unavailable**; Windows runtime нового orphan-сценария
и его изображения ожидаются отдельно. Живой AutoCAD не проверен.

Воспроизведение с null-шагами относится к принимаемой API/legacy-ветке
движка: текущий диалог ATFRAME задаёт положительные числа. Диагностика
утверждает только отсутствие сохранённой кандидатной ссылки; наличие и
тип фактического крепления остаются неопределёнными. Полный 2В/3А и
автоподбор этим инкрементом не открываются.
