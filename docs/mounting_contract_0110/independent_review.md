## Проверка кода и доверительных границ

Новый индекс работает только с выбранными физическими направляющими уже проверенного снимка. Один member входит в него один раз; сохранённые копии отчётов и частичный выбор зон не создают дополнительных связей. Ключ — физический bracket ID, поэтому разные ID в одинаковых координатах не объединяются.

Общий валидатор проверяет существование ID, единственность каждого bracket ID внутри одной направляющей, принадлежность тому же source run и зоне, состав всех направляющих исходного прогона, а также конфликтующие копии паспортов. Новый адаптер используется после этой проверки; отказавший источник до вывода не допускается. Исходные DTO не меняются.

Дополнительная работа линейна по выбранным направляющим, ссылкам и длине выдачи. Нет поиска всех кронштейнов для каждой направляющей. Общий список rail ID разбивается по границам идентификаторов; каждый peer ID выводится один раз на общий bracket ID. В строке направляющей хранится короткое число общих кандидатов, а не повторный список. Нет новых CAD-чтений, ModelSpace scan, перестроений, файлов/PDF/сети или запуска Python при просмотре.

Новые строки сообщают неопределённую монтажную принадлежность. Они не запрещают общую опору, не объединяют куски ГП, не назначают fixed/sliding, нагрузки, реакции или непрерывность. Не добавлены пользовательский ввод или галочка, закрывающие неизвестное. Прежние `MountingStatus=not_confirmed`, `AutomaticBracketSelectionAllowed=false`, `not_modeled/not_verified` и отказ явного каталога в расчётном режиме сохраняются.
