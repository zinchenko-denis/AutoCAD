# Следующий ограниченный пробел жизненного цикла ATFNODE

Read-only ревизия от `16c7307ce42715721ee7835d2dc90955e2229781`, 01.10.2026. Подтверждённого дефекта продукта не найдено; ниже — конкретный ещё не доказанный переход приёмки. В текущую итерацию команды ведомостей он не включается.

Нужен один сценарий на настоящей канонической зоне и проекте: создать N1 → изменить проект → отменить либо получить отказ при создании N2 → проверить сохранность N1 → успешно создать N2 → проверить обе схемы. N1 должна сохранить собственные owner/definition, исходный паспорт и тело, оставаясь stale по старому проекту. N2 должна иметь новые owner/definition и свежий снимок. Намеренно изменённый проект должен остаться изменённым; отказ новой вставки не должен откатывать чужое законченное изменение источника.

[FrameNodeCommand.Create](../../AFrame/src/AFramePlugin/FrameNodeCommand.cs#L43) создаёт новый экземпляр; после точки проверяет окружение и актуальность перед renderer/store ([граница записи](../../AFrame/src/AFramePlugin/FrameNodeCommand.cs#L77)). [Check](../../AFrame/src/AFramePlugin/FrameNodeCommand.cs#L99) отдельно проверяет сохранённое тело и нынешний источник; [ReadSource/VerifyFresh](../../AFrame/src/AFramePlugin/FrameNodeCommand.cs#L122) разрешают источник через каноническую штриховку. [FrameNodeStore.Write](../../AFrame/src/AFramePlugin/FrameNodeStore.cs#L23) запрещает заменять существующий паспорт, [Read](../../AFrame/src/AFramePlugin/FrameNodeStore.cs#L55) сверяет ссылки owner/definition/zone, текстовые handles и digest тела. По прочитанному коду эти границы согласованы; оснований заранее менять их нет.

Пробел в доказательстве: [NodeCadProbe](../../tools/node_geometry_0110/NodeCadProbe.cs#L66) исполняет actual command/renderer/store, но проверки cancel и отказов записи начинают с пустого `Fresh()`, а `ZoneGeometryGuard` заменён [fixture seam](../../tools/node_geometry_0110/NodeCommandDoubles.cs#L49). [LimitedPilotProbe.Node](../../tools/limited_pilot_0110/LimitedPilotProbe.cs#L223) связывает реальные параметры проекта и зоны с чистым Snapshot/Drawing и дословным условием свежести; сам ATFNODE command/renderer/store там не работает. Склейка этих PASS не доказывает сохранность старого физического узла в общей базе.

Минимальная будущая проверка: сравнить у N1 ссылки, RecordDigest и CadContentDigest до/после неудачной вставки; исполнять реальный Check, ожидая отказ по актуальности источника. Затем успешная N2 должна пройти Check, а N1 — остаться stale. Изолированный rollback double можно использовать только с точным перечислением моделируемых свойств; native AutoCAD rollback/Undo/COPY/SaveAs/save-open остаются NOT_RUN. Подключение полного Node в quantity DB требует согласовать различное владение `Database.Add` в двух моделях doubles, а не объединить два независимых мира по одинаковым строковым ID.

Файл/класс с именем NodeNativeCommandProbe в исходном срезе репозитория не найден; фактический существующий стенд — NodeCadProbe/test_node_cad.py. Монтаж 2В, расчёт 3А и автоподбор остаются закрыты; новых источников или инженерных характеристик эта ревизия не вводит.
