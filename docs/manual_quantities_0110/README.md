# Проверка Q-06: ручные элементы в фасадных ведомостях

База — `2e0abf221871480a9551b452f7ce51abbd6c4e92`. Это проверка фактических C# mapper, CAD-адаптера, хранения и смешанного чтения, без запущенного AutoCAD. Приватные исходные DWG и геометрия проектов в тесты не включены. Синтетическая кассета воспроизводит только подтверждённую структуру образца: один замкнутый контур, 12 вспомогательных штриховок, атрибуты и динамические размеры; её числа не являются проектными характеристиками или нормами.

Итоговые общие результаты, входные SHA-256 и неизменность кода следует проверять по `verification_manifest.json`. Обязательный runner сохраняет прежние 35 групп и добавляет 5 групп Q-06; это 40 групп. Установочный выпуск этим прогоном не собирается и не публикуется.

## Независимые сценарии

`manual_cad/manifest.json`: **92/92 PASS**. Настоящие `ManualQuantities`, `ManualQuantityGeometry`, `FacadeQuantityStore` и обе его частичные реализации выполняются с инструментированными CAD doubles и зонами настоящего Python-движка.

Проверены:

- одна физическая кассета при 12 вспомогательных штриховках, текстах и атрибутах; площадь действительного контура; поворот, зеркальность, неравномерный масштаб и базовая точка блока;
- реальные имена и единицы dynamic-свойств, отсутствие вызовов setters, отказ неоднозначных атрибутов/параметров, неверных единиц, нулевого масштаба, неплоской геометрии и вложенной сборки;
- LINE с длиной по концам и штучный символ без выдуманной длины/площади;
- сохранение/повторный импорт без удвоения физических идентификаторов, выбор марки/штриховки/детали, совместные generated/manual отчёты облицовки и подсистемы;
- предупреждение о совпадении отдельных объектов внутри партии, между партиями, зонами и ручными/созданными деталями; оба объекта остаются в количестве;
- явный список неучтённых объектов и отказ пустой неподтверждённой выборки без ложного нуля;
- изменение всех выбранных объектов между preview и Apply, включая отклонённый объект; изменение параметров, атрибутов, геометрии, видимости внутри определения и зоны после регистрации;
- неизменяемые версии правил, утрата/подмена индекса, anchor, правила, паспорта или soft reference; удалённый индекс целиком не скрывает оставшиеся ручные детали;
- копия метаданных не становится новой учтённой деталью до явного импорта; снятие копии не удаляет назначение оригинала; очистка исправляет удалённые ссылки и сохраняет геометрию;
- удалённая зона допускает явное снятие выбранных ручных назначений, сохраняя остальные; отмена preview и отмена при повторной проверке до первой записи не меняют старый индекс;
- ручной импорт не обходит отсутствующий старый generated-паспорт; legacy результат только на исходной марке требует этой марки/повторного построения, а не выдаёт неполный успешный состав; устаревшая чужая зона не расширяет область ведомости.

Чистый mapper имеет 47 сценариев; отдельный выходной probe проверяет 11 сценариев actual C# presentation model и 15 независимых проверок XLSX через openpyxl. Данные DWG/XLSX используют общие строки; это не проверка нативного объекта AutoCAD Table или формы.

## Производительность

`performance/manual_cad/` — **12/12 PASS**, исходники неизменны; [счётчики и наблюдаемое время](performance/manual_cad/OBSERVATIONS.md). Содержит actual Preview, Apply, Read через владельца и Read при выделении всех ручных деталей. Режимы — только ручные, только созданные и смешанные. Размеры — 10, 100, 1 000 и 10 000 объектов каждого происхождения; в смешанном случае физических деталей вдвое больше. Номера соответствуют контролируемой фикстуре полилиний, не реальному динамическому альбому.

CI выполняет первые три размера: 9 случаев с линейными верхними границами CAD/Xrecord/point-вызовов, единственным обходом ModelSpace и отсутствием записи при чтении. Импорт не обходит ModelSpace. Выбор всех ручных деталей должен давать тот же полный состав и отпечаток, что выбор владельца. Порогов в секундах нет. Большой локальный прогон добавляет 3 случая по 10 000.

Чистый mapper отдельно проверяет 10k/50k/150k и повторную оценку с подготовленным правилом. Эти измерения не включают native CAD API, динамическую оценку блоков, форму, регенерацию, файл DWG или работу Python-движка. Прежние проверки чистой агрегации, движка и Store сохраняются в общих группах.

RSS/Peak Working Set относятся ко всему процессу фикстуры, включая подготовленные CAD doubles, исходные DTO, preview и предшествующие фазы. `GC.GetTotalMemory` — наблюдение управляемой памяти, а не отдельная стоимость чтения. Нулевое недоступное значение RSS записывается как `null`. Одиночные времена стенда не гарантируют скорость AutoCAD.

## Воспроизведение

Из корня репозитория с Python 3.12, shapely/openpyxl/ezdxf и Mono/mcs:

```bash
python tools/atr_review_3009/run_checks.py --out /tmp/q06-gates
python tools/manual_quantities_0110/test_manual_core.py --out /tmp/q06-core
python tools/manual_quantities_0110/test_manual_core_perf.py --out /tmp/q06-core-perf
python tools/manual_quantities_0110/test_manual_cad.py --out /tmp/q06-cad
python tools/manual_quantities_0110/test_manual_cad.py --performance --large --out /tmp/q06-cad-perf
python tools/manual_quantities_0110/test_manual_output.py --out /tmp/q06-output
python tools/fixes_3009/compile_facades.py --references /path/to/extracted/nuget-packages --out /tmp/q06-compile
```

Windows CI компилирует `tools/manual_quantities_0110/ManualCadCheck.csproj` как net48 и передаёт путь к EXE через `--exe`; остальные команды закреплены в `.github/workflows/check.yml`. Отсутствующие компиляторы или исходники дают BLOCKED/отказ, не успешный пропуск. Воспроизводимые фикстуры строятся из публичного исходного кода, приватные файлы не требуются.

Doubles не моделируют нативную изоляцию/откат транзакций, динамическое вычисление блоков, COPY remapping, Save/повторное открытие, Undo/Redo или Esc во время записи. Эти сценарии, форма, собственный DWG/XLSX откат и реальные блоки остаются живой приёмкой по [MANUAL_QUANTITIES_01.10.md](../MANUAL_QUANTITIES_01.10.md). Ручное сопоставление подтверждает только указанную пользователем номенклатуру и измеряемую геометрию; каталог, несущая способность и нормативный расход не выводятся из него.
