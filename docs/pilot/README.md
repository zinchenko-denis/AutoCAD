# Короткий маршрут для Германа

[Две страницы Word](Facades_Pilot_Quick_Start.docx),
[PDF](Facades_Pilot_Quick_Start.pdf) и [редактируемый текст](PILOT_QUICK_START.md) описывают проверку исправленного
выпуска после build-105. Номер установщика и готовность к передаче определяются
[текущим планом](../CURRENT_MILESTONES.md). Старый установщик не содержит новых исправлений.

Откройте [учебный DXF](assets/Facade_18x12_15windows.dxf): одна стена
18×12 м и 15 окон 1,5×1,5 м; единицы — миллиметры. Это исходные контуры,
а не готовая зона или результат AutoCAD. Оба наружных края в упражнении
обозначены как внешние углы здания. Площадь без окон — 182,25 м².

Геометрия одинакова с воспроизведением исправления расчёта и резки:
нижние левые углы окон X=1500/4500/7500/10500/13500,
Y=1200/4200/7200 мм. Это явно заданный учебный пример, а не
неполученный исходный DWG независимого ревизора. Число «190 кусков»
из его отчёта не используется как эталон этого файла.

Маршрут: установка → зоны → расчёт на окнах → ручная расстановка →
облицовка и ведомости → сохранение и участок своего фасада.
Живая проверка ещё требует выполнения инженером; автоматические тесты
не заполняют его ответ. Достаточно короткого списка замечаний и файлов,
без обязательного длинного протокола.
