Пять реальных C# воспроизведений показали: одинаковые заявленные плоскости
дают просвет 20 мм при разных длинах КР2/УК, но не доказывают сборку. АТР и
расчётный пример не закрывают посадки, перехлёст и регулировку. Поэтому добавлен
отдельный монтажный отчёт с выбранными изделиями, семью недостающими связями

снимок и не добавляет CAD-чтений. Живой AutoCAD остаётся отдельной приёмкой;
нового выпуска и изменений main в этом инкременте нет.

## Решения, которые нельзя откатывать без обсуждения

- Порядок: зоны → раскладка → подсистема → спецификация; оси стоек и ряды кляммеров/шин приходят из
  метки раскладки (joints_x / rows_y). Шаги кронштейнов — выход расчёта (альбомы шагов не дают).
- Ортогональная: ряды кронштейнов = низ + 300 + 600·k (пять кронштейнов на 3 м) — правило Германа.
- Подбор профиля не увеличивает шаг кронштейнов — лимитирует анкер (frame_calc).
- Вертикальная: у окна направляющие в 100 мм от грани («бетон колется»), длина = окно + 50/50;
  межэтажная: у окна — НСП вдоль откоса от перекрытия до перекрытия (30.09, АТР тип 4).
- Плитка (клинкер/бетон): вертикали заданным шагом, не по швам; шины трёх видов; стык хлыстов — на
  направляющей; шина без опоры удлиняется до ближайших направляющих.
- Движки — только стандартная библиотека (заморозка PyInstaller); дублирование помощников между
  бандлами сознательное (бандлы обновляются независимо).
- Сборка — только после тестов; выкладку проверять скачиванием и дайджестами.

## Правила работы, выстраданные на ошибках

- Просьба Германа — сразу дословно в NEXT.md; в следующем PDF — «сделано / в работе / вопрос» (одна
  видео-просьба однажды потерялась).
- **Перед вопросом Герману — альбомы техрешений держателя системы и ТЗ** (30.09: ответ на вопрос про
  межэтажную был нарисован в АТР Вектор-1). Нет альбома — попросить (нужен «Вектор-4» и свежий
  «Вектор-1»).
- Числа — только после прогона; гипотезу, которую опроверг тест, признавать.
- Патчи — заменами по якорю с проверкой «ровно одно вхождение»; коммит и push после каждого блока.
- Токены — никогда в файлы, коммиты, логи (репо публичный).
