# VitrageGen

Генератор витражей/светопрозрачных конструкций ИЗ БЛОКОВ по чертежу АР.
Отдельная программа (НЕ развитие ATableSpec); связка — блочный контракт:
сгенерированный витраж ATableSpec ест без правок (спецификация и раскрой
получаются «даром»). Рабочее имя, финальное — на усмотрение Дениса.

- `src/VitrageGenPlugin/` — C#-плагин (.NET Fx 4.8, AutoCAD.NET 24.0),
  команда `ATVITRAGE`: 2 точки проёма + диалог → план → вставка вхождений.
- `engine/vitrage_plan.py` — py-движок расчёта сетки (замораживается
  PyInstaller в `vitrage_plan.exe` при релиз-сборке), `test_vitrage_plan.py` —
  юниты + сверка с эталоном.
- `bundle/VitrageGen.bundle/` — заготовка бандла автозагрузки.
- `docs/CONTRACT.md` — блочный контракт (доказан числами по эталону).
- `docs/NEXT.md` — состояние проекта и хэндофф (ЧИТАТЬ ПЕРВЫМ).

Этапность (каждый этап — рабочий продукт): Э1 полуавтомат без распознавания
(текущий), Э2 автозахват габарита проёма кликом, Э3 членение по импостам АР,
Э4 пакетно по фасаду.
