# Сравнение поведения после сборки 103

Воспроизводители причинных переходов на одинаковых входах. Исторические
исходники извлекаются через Git в новые каталоги, рабочая ветка не переключается.
Нужна история репозитория с тегами `build-103` — `build-110`, Python 3.12,
Mono/mcs. Это инструменты разработчика; они не создают комплект для конструктора.

Запуск из корня репозитория (каждая выходная папка должна отсутствовать):

```bash
python3 tools/regression_history/frame_history.py --repo . --out /tmp/frame-history-new
python3 tools/regression_history/attile_history.py --repo . --out /tmp/attile-history-new
python3 tools/regression_history/menu_history.py --repo . --out /tmp/menu-history-new
python3 tools/regression_history/replay_zone_quantity_history.py --repo . --out /tmp/zone-history-new --source-sha a5cf5066a4e673efef0b115ebe13738b7d305b4b
```

| Инструмент | Что исполняется | Граница доказательства |
|---|---|---|
| `frame_history.py` | Полный Python engine каждого среза, 31 одинаковый JSON-запрос | Геометрия и отказы движка; нет AutoCAD/GUI. Числа относятся к явно заданным тестовым фасадам, не к DWG Германа. Включён текущий HEAD, разрешённый до запуска. |
| `attile_history.py` | Настоящие исторические MakeDynRef/TrySetNum/ApplyLook, обе ветви sample/definition | Поведение свойств задано doubles; фактические ограничения приватного блока не устанавливаются. Срез `audit-2026-10-09` и doubles закреплены на a5cf506. |
| `menu_history.py` | Настоящие FacadesClassic трёх модулей из восьми выпусков | COM/CAD doubles; фактическая CUI-сессия и предупреждение ACAD:Фасады не воспроизводятся. Используется текущий тестовый helper, его SHA записывается. |
| `replay_zone_quantity_history.py` | Исторические guards, QuantityStore и отдельно дословный Fingerprint | Остальные зависимости и входы закреплены `--source-sha`; это изоляция причины, не запуск старого установочного пакета целиком. |

Нулевой код выхода означает **совпадение с проверяемой историей поведения**.
Ожидаемые отказы старых версий остаются FAIL пользовательского сценария;
они не становятся подтверждением его работоспособности. Исчезнувший тест,
неожиданный исход или неполный прогон должен нарушать сравнительную проверку.
Геометрический допуск старого адаптера и точность свойств показываются отдельно.

Скрипты сохраняют точные SHA источников, результаты и ограничения в заданной
папке. Большие отчёты и копии исходников не добавляются в Git. Подтверждённые
причины, текущие исправления и оставшиеся действия находятся только в
[CURRENT_MILESTONES](../../docs/CURRENT_MILESTONES.md).

Эти проверки не заменяют [полный нативный стенд](../native_autocad/README.md).
Не использовать успешный исторический replay как разрешение на выпуск.
