# Аудит границы монтажного контракта, 2В3

Запуск из корня репозитория с Python и рабочими .NET compiler/runtime:

```sh
python3 tools/pilot_completion_0110/audit_interface_mapping.py --out /tmp/pilot-interface-audit
```

Код выхода 0 означает, что аудит воспроизвёл текущий контракт и прошёл
контроли целостности. Он **не разрешает монтаж или расчёт**.
При отсутствии .NET стенда аудит возвращает 2, а не пропускает проверки.

Цепь: настоящие `FrameSettings.Validate/EngineParams/SysOverride`, движок,
`ValidateEngineReport`, извлечённый настоящий `FrameQuantities`, общий core
и `ConnectionTableData`. CAD handles/fingerprints представлены явными
doubles. AutoCAD, клики WinForms, DWG и XLSX этот аудит не исполняет.

Два допустимых выбора с ручными шагами 800 дают разные декларации и
одинаковые массивы геометрии: по одному ГП, четырём условным кронштейнам
и четырём кандидатным парам. Producer создаёт разные реальные run/element
ID каждого прогона. Физические УК и типизированные ГП–УК / УК–КР2 отсутствуют.
Контроль без выбора остаётся в прежнем Standart/unavailable.

Ожидаемый результат: 131 проверка `PASS`, инженерная оценка `BLOCKED`,
полный приёмочный цикл `NOT_RUN`. Негативные контроли отдельно проверяют
утрату/подмену декларации, происхождения, ID и назначения изделия;
реальные settings/engine/core отказывают на своих границах. Аудит
не содержит разрешающего READY-механизма: будущий подтверждённый контракт
потребует пересмотра эталона и независимой инженерной ревизии.

Манифест сохраняет исходные запросы/ответы, таблицы, trace, негативные
контроли, хеши исходников и результатов. Извлечённый producer учитывается
отдельно как generated artifact. Замеры компиляции, движка, producer,
core и таблицы относятся только к стенду.

Аудит входит в обязательные `run_checks.py` (56 групп) и Windows `check`;
CI сохраняет артефакт `pilot-completion-contract`. Принятые доказательства —
`docs/pilot_completion_0110/`. План и границы завершения —
`docs/PILOT_COMPLETION_PLAN_01.10.md`; следующий агент начинает с
`docs/SESSION_PROMPT_AFTER_2V3_01.10.md`.
