## Запуск

Нужны Python 3.12, Shapely и openpyxl. Для компилируемых C# проверок —
`mono`, `mcs`, System.Web.Extensions и System.IO.Compression/FileSystem.
AutoCAD и оконный сервер для этих новых воспроизведений не требуются.

Из корня repo одной командой:

```bash
python3 tools/review_3009/run_review.py --out /tmp/autocad-review-3009
```

Код возврата 1 означает найденные нарушения; 2 — заблокированные проверки;
0 — отсутствие нарушений в пределах этих проверок. Выход 0 не означает
инженерной приёмки или успешной проверки AutoCAD. Логи и manifest.json
пишутся в `--out`; без параметра используется новый временный каталог.
Файл исполняемой C# пробы массы также временный.

В среде ревизии Mono распакован локально в scratch; путь этой временной
установки не является зависимостью проекта. На другой машине достаточно
доступных `mono` и `mcs` в PATH. Новые тесты используют синтетические входы,
приватный `atspec-testdata` им не нужен.

Точное сравнение кляммеров в нескольких тестах использует множество и не
является самостоятельной проверкой отсутствия дубликатов. Тест коротких
направляющих моделирует явный C# фильтр прямоугольников, не реальные
GeometricExtents динамических блоков. Copy doubles не запускают COPY/Undo.
Материальные коэффициенты сопоставлены с источниками проекта; нормативная
достаточность этих значений для любого объекта не утверждается.

Для композита тест запрещает повторение идентичного выхода КГ, но не
запрещает будущий материально-специфичный крепёж в коллекции `clamps`.
Отрицательные параметры могут безопасно отклоняться исключением ValueError
или ответом ok=false. При изменении публичной схемы контракта эти probes
надо адаптировать с сохранением проверяемого инварианта.
