# Проверка фактических кусков направляющих

`frame_calc.py` сохраняет арифметику переданных расчётов Вектора и первоначальный
подбор профиля/шага. После расстановки `frame_topology.py` проверяет каждый
физический кусок: реальные опоры, пролёты, свободные концы и выбранное сечение.
Одинаковые геометрические схемы и цепочки рассчитываются один раз на операцию.
Стыки между разными кусками не передают момент в этой модели, даже при нулевом зазоре.

`frame_beam.py` — линейная призматическая балка Эйлера–Бернулли с постоянным EI,
равномерной поперечной нагрузкой и простыми поперечными опорами без осадки.
Это та же балочная идеализация, которую использует исходная методика;
фактическое исполнение монтажных соединений она не подтверждает.
Трёхмоментные уравнения решаются за O(n), экстремумы прогиба ищутся по корням
производной точного полинома. Свободные концы и неравные пролёты включены явно.

Для одного пролёта без свесов получаются `M=qL²/8`, `R=qL/2`,
`f=5qL⁴/(384EI)`. Для двух/трёх/четырёх и более пролётов исторические
коэффициенты Вектора остаются нижними границами расчётных значений.
Если реальная геометрия даёт большие момент, реакцию или относительный прогиб,
используется большее значение. Например, точный прогиб двух равных пролётов
при сплошной нагрузке имеет коэффициент 0.00541612, а не округлённый 0.0052.

Ветровая реакция не подменяет весовую грузовую площадь. Для веса сохраняется
полоса не меньше наибольшего пролёта и учитываются крайние полосы:
`max(Lmax, нижний свес + Lfirst/2, верхний свес + Llast/2)`.
Это не распределение веса между реальными неподвижными/подвижными узлами.
Предел прогиба L/150 сохранён для каждого фактического пролёта; для свободного
конца тот же предел применяется к его собственной длине как консервативная
проверка. Это не новая допустимая длина консоли производителя.

При непрохождении вертикального куска программа пробует меньший шаг по
существующей сетке 50 мм до 200 мм только для этого куска. Границы, профиль,
заданные торцевые отступы и общие с соседним куском опоры не меняются.
Неудача даёт адресный отказ и сохраняет прежний каркас. Отдельный кусок
с менее чем двумя опорами не получает положительного расчёта.

Не подтверждены этой проверкой: fixed/sliding и температурные перемещения,
реальная жёсткость соединений, распределение веса, прочность горизонтальных
НГП/СП, пространственная работа и проект в целом. Межэтажная автоматическая
расчётная выдача остаётся закрыта. `static_model.status = not_verified`
сохранён; `member_calculation` отдельно сообщает результат ограниченной проверки.

Источники формул:

- [MIT OCW, Unified Engineering, M5–M8: EI·y″ = M и балка под равномерной нагрузкой](https://ocw.mit.edu/courses/16-01-unified-engineering-i-ii-iii-iv-fall-2005-spring-2006/f66f80cd5fbd5cf8295d7b1e1e28a368_gm5_8_notes.pdf).
- [American Wood Council, Beam Design Formulas, рисунки 1, 22, 29, 31; копия Purdue CE474](https://engineering.purdue.edu/~ce474/Docs/DA6-BeamFormulas.pdf). Использованы балочные формулы, не характеристики древесины.
- Исходные стальные сечения, нагрузки и коэффициенты Вектора — прежние `frame_calc.py`, `test_frame_calc.py`; приватные оригиналы не копируются.

Проверки: `python AFrame/engine/test_frame_beam.py` и прежние
`test_frame_calc.py`, `test_frame_topology.py`, `test_frame_topology_index.py`.
