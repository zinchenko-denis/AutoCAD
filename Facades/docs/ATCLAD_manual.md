# AFacades / ATCLAD — раскладка облицовки (этап 2, сборка 21.07)

Инструкция для Германа. PDF-версия отдана Денису для пересылки.
Этап 2 сделан ОТДЕЛЬНОЙ командой, как вы просили: **ATFZONE** (зоны,
площади, ведомости) и **ATCLAD** (раскладка кассет) — независимые шаги.
Раскладка работает по вашим ответам на В1–В8: минимальная подрезка
150 мм; вертикальные швы от границ проёмов, продолжаются в рядах над и
под проёмами; остаток простенка ≥300 — один подрезной в середине,
меньше 300 — целая плитка в середине и два равных подрезных по краям;
размеры камня — динпараметры «ширина»/«высота»; видимость не трогаем.

## Установка/обновление (2 минуты)

1. Скачать тот же архив:
   https://github.com/zinchenko-denis/AutoCAD/releases/download/latest/AFacades.bundle.zip
2. Распаковать и ЗАМЕНИТЬ папку `AFacades.bundle` в
   `%APPDATA%\Autodesk\ApplicationPlugins\` (AutoCAD закрыть).
3. Запустить AutoCAD. В командной строке:
   `AFacades загружен (сборка DLL от ДД.ММ.ГГГГ ЧЧ:ММ)` — дата должна
   быть 21.07.2026 или новее, иначе у вас старая сборка.
   **Эту дату указывайте в каждом сообщении с замечаниями.**

## Подготовка (на чертёж)

1. Зоны созданы командой ATFZONE, рядом с чертежом лежит файл
   `<имя чертежа>_fzones.json` (галка «сохранить JSON» в ATFZONE).
   Если файла нет — перезапустите ATFZONE по зонам или выбирайте в
   ATCLAD не зоны, а сами замкнутые полилинии контуров.
   Раскладка БЕЗ зон тоже работает: просто замкнутые полилинии,
   контур внутри контура = проём.
2. Вставьте в чертёж ОБРАЗЕЦ блока облицовки (универсальный блок /
   «кассета 2»): выставьте в образце размеры камня («ширина» и
   «высота», например 600×600) и положите его на слой облицовки —
   камни раскладки лягут НА СЛОЙ ОБРАЗЦА с его размерами как
   максимальными.

## Работа по шагам

1. Команда **ATCLAD** → выберите штриховки и/или марки зон (как в
   ATFTABLE) и/или замкнутые полилинии. Можно одной рамкой — лишнее
   игнорируется.
2. Укажите образец блока облицовки. Программа сообщит: блок, слой,
   размер камня с образца. Параметр видимости кассеты не трогается.
3. «Точка уровня старта облицовки (низ первого ряда)» — кликните
   уровень старта. Это ОБЩИЙ ГОРИЗОНТ: сетка рядов одна для всех
   выбранных зон; ниже отметки камни не кладутся.
4. Русты, мм: вертикальный (между камнями в ряду), затем
   горизонтальный (между рядами). По умолчанию 8; Enter — принять.
5. «Способ раскладки [Проемы/Край]»:
   - **Проемы** (по умолчанию, Enter) — вертикальные швы совпадают с
     границами оконных/дверных проёмов и продолжаются в рядах над и
     под ними; остаток простенка: ≥300 — один подрезной камень в
     середине, <300 — целая в середине, два равных подрезных по краям;
   - **Край** — целыми слева направо от левого края контура, подрезка
     у примыканий к проёмам и у правого края.
6. Готово: вставки кассет на слое образца, у каждой фактический размер
   (подрезанные — через «ширина»/«высота»). В командной строке сводка:
   всего/целых/подрезных, по зонам, замечания (что и почему пропущено).

## Что зашито по вашим правилам

- Минимальная подрезка 150 мм: камень уже — НЕ ставится, в командной
  строке замечание «подрезка N < min_cut (×К)».
- Подрезка по высоте сама: верхний ряд, ступени контура, ряд над/под
  проёмом; полоса ниже 150 по высоте — пропуск с замечанием.
- Ниже отметки старта не кладём (замечание, на сколько контур ушёл
  ниже).
- МАРКИРОВКА и ЗАХВАТКА у вставленных кассет пока ПУСТЫЕ — вопрос №10.

## Перегенерация (повторный запуск)

Параметры раскладки и список камней хранятся на выбранных
штриховках/марках (ключ ATCLAD рядом с данными зоны).

- Поменяли контур → перезапустите ATFZONE по зоне → снова ATCLAD с ТЕМ
  ЖЕ выбором. Прежние камни зоны удалятся сами, лягут новые.
- При повторе выбирайте те же объекты, что в первый раз (выбрали
  штриховку — снова штриховку).
- Если контур двигали, а ATFZONE не перезапускали, ATCLAD зону
  ПРОПУСТИТ с предупреждением (площадь штриховки разошлась с
  сохранённой) — сначала ATFZONE.

## Ограничения версии (честно)

- Контуры с дугами (арки) пропускаются с предупреждением — вопрос №11.
- Блок без динпараметров «ширина»/«высота» — размеры спросятся
  числами, камни вставятся без подгонки размеров (все одинаковые).
- Копия зоны вместе с камнями помнит камни ОРИГИНАЛА — на копии
  сначала пересоздайте зону (ATFZONE), потом раскладывайте.

## Вопросы — просьба ответить вместе с тестом

- **В9.** Режим «от края»: подрезка у правого края/проёма получилась
  меньше 150 — оставлять пропуск (как сейчас) или переигрывать ряд по
  правилу простенка (целая в середине, подрезки по краям)?
- **В10.** Заполнять ли МАРКИРОВКУ камней при вставке (например,
  типоразмеры К-1, К-2, … по размерам камня — для спецификации), и что
  писать в ЗАХВАТКУ?
- **В11.** Арочные контуры: как вы раскладываете кассеты по дуге — и
  нужно ли это программе сейчас?

## Просьба для сверки

Пришлите один участок, разложенный ВРУЧНУЮ тем же блоком (как считаете
правильным), — DWG/DXF. Он станет живым эталоном: программа обязана
воспроизводить вашу раскладку в точности, как сделали с зонами и
размерами.
