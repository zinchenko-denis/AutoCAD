## Объект и система

Высота 14.6 м, стены монолитный ж/б; СПб, ветровой район II (w0=30 кг/м²),
тип местности Б (ПЗ) / В (общие данные и расчёт) — внутреннее расхождение
документа. Система «Вектор-1» Тип 1 (вертикальная), ТС № 4634-15.
АР-подоснова: шифр 05-2016-АР4, ПК «Фирма Проект» (исходные данные = ТЗ +
комплект АР от заказчика).

Подсистема: КР2-70-200 (кронштейн), УК-70-100 (удлинитель, по неровности),
профили ГП-60-40-1.2 (рядовые) и ГП-40-40-1.2 (у проёмов/углов), ПУ-1,
ШУ-70-400, ПП-70; анкер по испытаниям, вырыв ≥3000 Н.
Кляммеры КЛР-1/КЛР-1.2, КЛУ-1 (замыкающие ряды), КЛС-1 (старт), нерж. 1.2 мм,
min 2 заклёпки; **окраска кляммеров по RAL в цвет плитки** (коричневая 7013,
серая 7030, светло-серая 9002; на стыках цветов — правило приоритета).
Облицовка — керамогранит 3 видов: 600×600 Италон серый, 600×600 Керранова
светло-серый, **200×1200 Керама Марацци коричневый**. Швы **8(±2) мм**.
Утеплитель 150=100+50 (Rockwool Венти Баттс Н + Оптима), НГ, мембрана
TEND КМ-0; дюбели: 1-й слой ≥2, 2-й ≥5 шт. на плиту 1000×600, рандель ≥60
(⚠ ТР 161-05 требует ≥80 — расхождение), морозостойкость ≥150.

## КЛЮЧЕВЫЕ ЧИСЛА КАРКАСА (первый живой пример «шагов по расчёту»)

**«Рекомендации по каркасу» (листы схем): рядовая система по монолиту
(высота/шаг кронштейнов/шаг направляющих): рядовая зона 14.0/1200/608;
угловая зона 14.0/800/608.**

- **Шаг направляющих 608 мм = плита 600 + шов 8.** Раскладка облицовки
  ЗАДАЁТ каркас — подтверждение порядка «раскладка → подсистема».
- Шаг кронштейнов по вертикали: 1200 рядовая зона / 800 угловая зона
  (угловые зоны — повышенный отсос: аэродинамика −1.2 рядовая / −2.2 угловая,
  пиковая ветровая 76.2 / 139.7 кг/м²).
- Зазор между направляющими по вертикали 7…10 мм (температурный); в ПЗ — 10.
- Вынос облицовки от стены 230 мм; зазор плита-профиль 10; вентзазор min 20.
- У проёмов — отдельный профиль ГП-40-40, шаг кронштейнов 1200.
- Плита 200×1200: при шаге профилей <750 — обычный узел; при ≥750 —
  добавочный профиль ГП-40-40 + КЛУ-1 (узлы 3–5).
- **Доп. кляммеры: по середине горизонтальных торцов плит длиной >350 мм,
  НАЧИНАЯ С ВЫСОТЫ +5.000 м**, на полосе оцинковки ≥0.5 мм; для Италон
  600×600 (вариант 3) — без доп. кляммеров (листы 30–32).
- Короб проёма: дюбель-гвоздь 6×60 max 400 верх / max 600 бок, заведение
  min 150; влагоотвод ≤Ø8 шаг ≥100; НГ-утеплитель короба ≥75 кг/м³.
- Удлинитель: нахлёст min 30, крепёж min 15 от края (лист 29).
- Анкера от края: отступ дюбеля от края утеплителя min 100 (узлы).

## Состав и оформление листов (прообраз наших выходов)

**Ведомость (лист 1):** 1 ведомость; 2 общие данные; 3–6 раскладка облицовки
(по фасадам в осях 1-13, 13-1 + Виды 1-5 + Фрагменты 1-2, Н-А/А-Н,
Фрагмент 3-4); **3.1–6.1 схемы установки кронштейнов и направляющих — ПАРНЫЕ
к раскладкам** (тот же фасад: лист N облицовка / N.1 подсистема); 7–26 узлы
1–20 (+23.1 = узел 17.1); 27 двухслойный утеплитель; 28 противопожарный
короб; 29 крепление удлинителя; 30–32 схемы установки кляммеров вар. 1/2/3
(по типам керамогранита). Форматы: А2 раскладки/схемы, А4 узлы, А3 отдельные.

**Раскладка облицовки:** фасад с полной сеткой плит и ЦВЕТОВОЙ заливкой по
типам КГ; легенда с полными торговыми наименованиями; красные стрелки
«направление монтажа»; размерные цепочки по горизонтали и вертикали;
формулы рядов «200×9=1872», «200×15=3120»; высотные отметки по краям;
узловые выноски красным «У№(лист)»; проёмы — белые дыры; ПОЗИЦИОННЫХ МАРОК
ПЛИТ НЕТ — только размеры; примечание «размеры плит, отличные от
1200/600/300/200, уточнить при установке», «отметки согласно АР».

**Схема подсистемы:** та же развертка, вместо плит — каркас; условные
обозначения (кронштейн = красные точки, профили = синие вертикали, ПУ-1,
ШУ); цепочки шагов направляющих (608 базовый, у проёмов 274–546) и шагов
кронштейнов по каждой стойке; привязки к осям и граням проёмов; текстовый
блок «Рекомендации по каркасу»; примечания: «размеры между направляющими,
отличные от 304 и 608, уточнить при установке», «размеры по оси профиля»,
«зазор направляющих 7…10 на температурное расширение», «монтаж от базовых
точек».

**Узлы (21 шт.):** рядовые сечения (600×600, 200×1200 два случая, 1200×200),
наружный/внутренний угол, боковой/верхний откос, отлив, цоколь, парапет,
примыкания к плите перекрытия (3 варианта верхнего откоса под плитой),
к витражу (2 варианта, в т.ч. со стыком со штукатурным фасадом!), к
балконной плите (2 варианта). Шаблонные примечания: «* размер уточнить при
установке»; «** удлинитель применять по неровности основания»; «*** показано
условно, не входит в зону ответственности фасадных работ» (окна, витражи,
кровля, цоколь, штукатурный фасад — граница подряда прописана в узлах).

## Прочностной расчёт (стр. 51–59) — что считает системщик

Структура: исходные данные (масса КГ 25 кг/м², профиль 0.92 кг/м, шаги,
сталь R=2350/2136.4 кг/см², вынос e1=230) → пиковая ветровая (по зонам)
→ анкер (Nvir ≤ 305.9 кг: 207.0 рядовая / 168.9 угловая) → кронштейн КР2-70
→ удлинитель → профиль ГП-60-40 (напряжение + прогиб ≤ L/200: 1.4/0.5 ≤
6.0/4.0 мм) → профиль у проёмов ГП-40-40 → заклёпки (срез/смятие 172.2/130.2
≤ 269.2/220.2 кг). Каждый блок завершается «Условие прочности выполнено».
Вывод: система до 15 м, схемы 1200/608 и 800/608, анкер ≥3000 Н.

## Деление фасада и вычеты (ответ на вопрос блока A — частично)

- Базовое деление: РЯДОВАЯ зона / УГЛОВАЯ зона (по аэродинамике) — разный
  шаг кронштейнов при одном шаге направляющих.
- Расчётные подобъекты: каждый фасад в осях — свой лист; торцы/пилястры —
  «Виды»; надкровельные лифтовые шахты — свои виды с планом; зоны над
  входами — «Фрагменты»; балконы — узлами; цоколь ниже отметки — вне НВФ.
- Вычеты: проёмы/витражи — белые дыры; светопрозрачные, штукатурный фасад,
  кровля, цоколь — «не входит в зону ответственности фасадных работ».
- «Захватки» — только в технологии монтажа (ПЗ): оси на каждой захватке от
  углов и оконных блоков; >5 м — шаг ≤5 м. На чертежах границ захваток нет.

## Внутренние несоответствия проекта (кейсы для нашего валидатора)

1. Тип местности Б (ПЗ) vs В (общие данные, расчёт).
2. Титул расчёта «корп. 11,12,13» vs «корп. 10,11,12» в альбоме.
3. Плотность утеплителя: ПЗ ≥80 / схема ≥70 / узлы короба ≥75 кг/м³.
4. Зазор направляющих: ПЗ 10 vs схемы 7…10.
5. Рандель дюбеля ≥60 vs ТР 161-05 ≥80.
Вывод: даже боевые комплекты внутренне противоречивы — программа должна
кросс-проверять и подсвечивать такие расхождения, это фича.
