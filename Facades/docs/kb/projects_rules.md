# Правила из боевых проектов НВФ (обезличенная сводка)

Извлечено из двух реальных комплектов: **проект A** (2018, система
«Вектор-1», монолит, ~15 м) и **проект B** (2025–26, система «Standart»/
поставщик КАФТ, стилобатный пояс НВФ + СФТК выше). Полные конспекты с
реквизитами — в ПРИВАТНОМ репо `atspec-testdata/docs/kb_private/`
(решение Дениса 18.07i: реквизиты боевых проектов в публичный репо не кладём).

## Состав итогового комплекта (что выдаёт проектировщик)

Проект A: ведомость → общие данные → раскладки облицовки по фасадам →
ПАРНЫЕ схемы подсистемы (лист N облицовка / N.1 каркас) → узлы (~20) →
схемы (утеплитель, короб, удлинитель, доп. кляммеры) + отдельные тома:
спецификация, прочностной расчёт, ПЗ.
Проект B: то же ядро (л.1–2 общие данные; л.3–6 раскладки облицовки;
л.7–10 раскладки подсистемы ПАРАМИ; л.11–20 узлы), а ведомости — ОТДЕЛЬНЫЕ
EXCEL-файлы с живыми формулами: «СО» (спецификация: материалы) и «ВР»
(ведомость работ). Итог: наш пайплайн должен выдавать DWG-листы + xlsx.

## Структуры таблиц (эталон генератора)

СО: `Поз. | Наименование и техническая характеристика | Тип, марка,
обозначение | Код продукции | Поставщик | Ед. изм. | Кол-во | Масса 1ед. |
Примечание`; разделы строками-заголовками: 1. Облицовка; 2. Утепление;
3. Система НВФ; 4. Изделия из оцинкованной стали. Оцинковка — текстом с
шириной развёртки: «Отлив… t=0.7… RAL …. Lразв=345мм», единица м.п.
ВР: `Поз. | Наименование работ | Ед.изм. | Кол-во | Примечание`; те же
разделы; работы по системе в м² (= площадь облицовки), примыкания в м.п.;
примечания ссылаются на узлы («См. узлы 4, 5, 6, 7»).

## Паттерны расчёта ведомостей (сняты с живых формул xlsx)

- Площадь нетто = брутто − вычеты (прямо формулой в ячейке).
- Утеплитель (м²) = площадь нетто; работы по кронштейнам/направляющим
  нормируются в м² той же площади.
- Запасы на раскрой: утеплитель ×1.1, мембрана ×1.2, плитка ~+11% (в шт).
- Дюбели тарельчатые = м² × норма (проект B: 12 шт/м² с учётом крепления
  мембраны; проект A: ≥5 шт/плиту 1000×600 + ≥2 на внутренний слой).
- Термомосты = количеству кронштейнов своего типа.
- Заклёпки кляммеров = 2 × Σ кляммеров.
- Крепёж примыканий = погонаж / шаг (шаги 400 верх / 600 бок / 400 клипса).
- Заклёпки системы = Σ (кронштейны × коэффициент по типу) + погонажи полос
  / шаг.
- Кляммеры по ролям: рядовой / угловой / стартовый считаются отдельно;
  в низких поясах с массой примыканий угловых и стартовых БОЛЬШЕ рядовых.
- ⚠ Константы (погонажи, числа проёмов) в формулы вбиты руками с чертежа —
  главный источник рутины и ошибок; именно их наша программа должна
  выводить из геометрии зон автоматически.

## Схемы каркаса двух систем (правила — атрибуты системы!)

| Параметр | Проект A (Вектор-1) | Проект B (Standart/КАФТ) |
|---|---|---|
| Схема | вертикальная, Г-профили 60×40 и 40×40 (у проёмов) | вертикальная, один Г-профиль 40×40×1.8 (хлыст 6000) |
| Шаг направляющих | 608 = плита 600 + шов 8, константа | от раскладки: ~605 (2 на плиту 1200 у проёмов), 862/1205 (1 на стык в глухих зонах) |
| Шаг кронштейнов (верт.) | 1200 рядовая зона / 800 угловая | 800 типовой (краевые 300–610) |
| Кронштейны | один тип + удлинитель по неровности | три роли: несущий NL / несущий NM / опорный S + термомосты |
| Швы облицовки | 8±2 | 5±2 |
| Терморазрыв направляющих | 7…10 мм | 10 мм, стык на несущем кронштейне |
| Доп. кляммеры над проёмом | зона 650 мм, при шаге >350, от отметки +5.000 | зона 1200 мм, полоса 0.7, отступ 300 |
| Дефшов здания | 20 мм, кронштейны min 100 от шва | 20±2, min 100 |
| Угол | ПУ-1, ШУ-400 | кронштейн min 150 от угла, ПУ1 ≥2 заклёпки |
| Короб проёма | дюбель-гвоздь 400 верх/600 бок; перфорация Ø5/400; дренаж ≤Ø8/≥100 | то же + герметизация стыков отлива, клипса-зажим 0.5 на саморезах 4×16, зазор плита–откос 25±2 (низкие проёмы) |
| Кляммеры к профилю | ≥2 заклёпки | ≥2 заклёпки (2 шт в формуле расхода) |
| RAL доборных | в цвет плитки, таблица приоритета на стыках цветов | один RAL по проекту |

Общее обоим (и АТР): вентзазор min 20 локальный (проектный 40 по ТР 161-05),
вынос облицовки ~230, отступ анкера от граней ≥100, мембрана поверх
утеплителя под дюбели.

## Раскладка облицовки — конвенции листов

- Позиционных марок плит НЕТ — сетка размерными цепочками; нестандартные
  размеры со звёздочкой «*размер для справки, уточнить по месту/натурным
  замерам».
- ЯКОРЯ: спецмаркер «Начало и направление раскладки» (стрелка) у осей по
  низу фасада; от деформационного шва раскладка расходится в обе стороны.
  Формулы рядов «600×n» / «200×9=1872».
- Проёмы — белые дыры в сетке; облицовка по простенкам с привязкой швов к
  граням проёмов.
- Встроенные элементы в облицовке: вентрешётки (с ведомостью марка→проём
  Ш×В→шт), люки дымоудаления, ниши кранов — «допустимо изменение раскладки
  подсистемы по месту» вокруг них.
- Границы работ прописываются примечаниями «показано условно, не входит в
  объём работ» (окна/двери/витражи, цоколь ниже отметки, кровля, СФТК,
  основание).
- Деление фасада: секции → фасады по осевым диапазонам → листы + ключ-план
  на каждом листе; сложные места — «Виды» и «Фрагменты» с своими сетками.
  Зонирование нагрузок: рядовая/угловая зона (проект A — разные шаги).
  «Захватки» на чертежах НЕ обозначаются (проект A: только в ПЗ по
  монтажу; проект B: в переданных томах нет).

## Стык НВФ ↔ СФТК (связка блоков B и C)

Проект B: НВФ — нижний пояс до фиксированной отметки, выше СФТК ОТДЕЛЬНЫМ
комплектом (свой шифр); стык — узел с отливом + отсечкой (м.п. в
ведомостях). Проект A: узел примыкания НВФ к витражу со стыком со
штукатурным фасадом. Формат зоны должен нести верхнюю/нижнюю границу зоны
по отметкам и тип соседней системы.

## Общие данные комплекта (лист 2 проекта B, дополнено 18.07j)

- Официальные имена прилагаемых ведомостей: **СО = «Спецификация
  оборудования, изделий и материалов», ВР = «Ведомость объемов работ»**
  (отдельные документы своего шифра, не листы альбома).
- **Актуальный нормативный стек фасадчика (2025–26):** СП 54.13330.2022,
  **СП 20.13330.2016** (нагрузки), СП 70.13330.2012, СП 28.13330.2017,
  СП 16.13330.2017, **СП 522.1325800.2023 «Системы фасадные навесные
  вентилируемые. Правила проектирования, производства работ и
  эксплуатации»** (профильный СП!), **ГОСТ Р 58154-2018** (материалы
  подконструкций НВФ), **ГОСТ Р 58883-2020** (правила расчёта
  подконструкций). ТР 161-05 и СП 20-2011 из kb/norms.md — историческая
  база; правила модулей сверять с этим стеком.
- Семантика «min 20»: минимальный зазор МЕЖДУ УТЕПЛИТЕЛЕМ И ВЕРТИКАЛЬНЫМИ
  НАПРАВЛЯЮЩИМИ 20 мм (общие указания п.6).
- Разгадка нормы дюбелей 12 шт/м²: 5 шт/плиту 1000×600 (≈8.3/м²) +
  4 шт/м² на крепление полотна мембраны ≈ 12. Мембрана вертикально,
  перехлёст полос 100–150 мм.
- Противопожарный короб (правила текстом, совпадают с узлами): единый
  герметичный барьер от стены до внутренней грани облицовки; сталь ≥0.7 с
  полимерным покрытием; крепление к основанию верх ≤400 / бок ≤600
  (дюбель забивной 8×60) + заклёпки 4×8 к вертикальным направляющим;
  крепление только к оконным блокам основанием НЕ считается; в верхний
  откос — НГ утеплитель 30 мм ≥80 кг/м³.
- **Перечень скрытых работ (6 актов) = этапы монтажа = разделы ВР:**
  кронштейны → теплоизоляция → мембрана → направляющие → отсечки и
  обрамления проёмов → облицовка.
- Захватки в комплекте отсутствуют полностью (и в общих данных).

## Следствия для модулей (сводно)

1. Выход пайплайна: DWG (раскладка + парная схема подсистемы + узлы-ссылки)
   + xlsx СО/ВР с формулами, а не константами.
2. Правила расстановки и нормы расхода — данные СИСТЕМЫ (плагинный
   справочник), не код.
3. Зоны: атрибуты верх/низ по отметкам, сосед (СФТК/витраж/цоколь),
   рядовая/угловая ветровая зона, встроенные элементы (решётки и пр.).
4. Автоматизируемое ядро ведомостей: геометрия зон → площади нетто,
   погонажи примыканий по типам узлов → формулы расхода по правилам
   системы. Ровно то, что сейчас вбивается руками.
