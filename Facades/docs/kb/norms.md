## ТР 161-05 (Москва, 2005) — правила проектирования НВФ

**Вентзазор — РАЗРЕШЕНИЕ противоречия сайта Вектора:** проектная величина
**не менее 40 мм** (п. 4.5); при монтаже минимум 40 с допустимым ЛОКАЛЬНЫМ
уменьшением у направляющего профиля **до 20 мм** (п. 7.19.2). Вот почему на
разрезах АТР Вектора стоит «min 20» (локальный у профиля), а в статьях — 40.

**Исходные данные для проектирования (п. 2.2)** — чек-лист для нашего
пайплайна: архитектурные чертежи фасадов (фактура/цвет облицовки, детали);
рабочие чертежи наружных стен с узлами; допустимая дополнительная нагрузка
на стены (от разработчиков фундаментов); план участка; для реконструкции —
акт обследования стен (несущая способность, отклонения от вертикали).

**Расчёты (п. 2.4–2.7):** прочностной (масса + ветер + двухстороннее
обледенение + температурные воздействия), по ВСЕМ участкам с учётом
конструктивных различий; аэротруба для жилых >75 м / общественных >50 м
непрямоугольного сечения; теплотехника; коррозия; пожарная опасность
(ГОСТ 30403-96) — для каждого объекта.

**Конструирование (р. 4):** длина направляющих: **сталь ≤6.6 м, алюминий
≤3.6 м** (температурные деформации); запрет вывесок/рекламы/светильников на
каркас и облицовку; >75 м — индивидуальные ТУ, кронштейны только в несущие
ж/б/металл элементы или спец. пояса; алюминиевые конструкции — только до
100 м высоты (п. 5.3.8).

**Материалы и долговечность (р. 5):** срок службы несущих элементов ≥30 лет
(II уровень ответственности) / ≥50 лет (I); исключить контакт разнородных
металлов; кляммеры — только коррозионностойкие стали Х18Н10Т/Х22Н6Т;
утеплитель однослойный НГ ≥80 кг/м³, двухслойный: внутренний Г1 30–80,
наружный НГ; облицовка: морозостойкость 150 циклов.

**Анкеры (ключевое):** коэффициент надёжности на вырыв **γm ≥ 5**; монтаж
ТОЛЬКО после натурных испытаний на вырыв (акты); отступ оси анкера от граней
(наружный угол, откос проёма) **≥100 мм**; глубина анкеровки: **бетон ≥50,
кирпич ≥80, лёгкий бетон ≥100 мм**; щелевой кирпич/пустотелые блоки —
сверлить без удара; краевая зона ≥2.5 диаметра.

**Тарельчатые дюбели:** рандель **≥80 мм** (⚠ в проекте Бугры ≥60 —
расхождение), морозостойкость ≥150 циклов, **≥5 шт. на плиту 1000×600**
(при двухслойной изоляции внутренний слой ≥4 шт.).

**Стены-основания (р. 6):** заполнение проёмов каркаса — полнотелый кирпич
или блоки ≥900 кг/м³; допуски: монолит от вертикали 15 мм, кладка 10 мм/этаж
и 30 мм/здание, местные неровности 5 мм по 2-м рейке; при превышении —
решение проектной организации с системщиком.

**Монтаж (р. 7–8):** последовательность кронштейны→утеплитель→мембрана→
направляющие→облицовка; шов утеплителя ≤2 мм, не оставлять открытым >15 сут;
мембрана: перехлёст 100 мм, 4 дюбеля/м², не поверх направляющих; температурный
зазор направляющих обязателен, монтаж без начального напряжения; облицовка
снизу вверх, зазоры по шаблонам; гарантия подрядчика ≥5 лет; обследования
НВФ каждые 4 года (>75/50 м — постоянный мониторинг).

**Противопожарное:** утеплитель НГ (наружный слой всегда НГ); оценка
пожарной опасности по ГОСТ 30403-96 для каждого объекта; требований к
рассечкам в вентзазоре в ТР НЕТ (появились в более поздних нормах —
уточнить по актуальному своду и пожарным заключениям).

## СП 20.13330.2011 «Нагрузки и воздействия» — ветер для фасадов

**Базовое:** w = wm + wp; **wm = w0·k(ze)·c**; γf = 1.4.

**w0 по ветровым районам (кПа):** Ia 0.17; I 0.23; II 0.30; III 0.38;
IV 0.48; V 0.60; VI 0.73; VII 0.85. (Карта районов — отдельная брошюра.)

**k(ze) по типам местности** (А открытая / В город, лес / С плотная
застройка >25 м): k = k10·(ze/10)^2α, α=0.15/0.20/0.25, k10=1.0/0.65/0.4;
таблица: 10 м → 1.0/0.65/0.4; 20 → 1.25/0.85/0.55; 40 → 1.5/1.1/0.8;
100 → 2.0/1.6/1.25. Эквивалентная высота ze — по соотношению h и d.

**Аэродинамика стен (прил. Д, табл. Д.2):** наветренная D=+0.8; подветренная
E=−0.5; боковые по зонам A=−1.0 (полоса e/5 от наветренного ребра), B=−0.8,
C=−0.5; e=min(b;2h). Внутреннее давление ±0.2 (μ≤5%).

**ПИКОВАЯ нагрузка для облицовки и креплений (п. 11.2, Д.1.17) — главное
для НВФ:** w± = w0·k(ze)·[1+ζ(ze)]·cp±·ν±.
- **cp+ = 1.2 (стены); cp− по зонам: угловые полосы шириной e/10 → −2.2;
  средняя часть стены → −1.2** (кровля: углы −3.4, края −2.4, центр −1.5).
- ν по площади сбора: <2 м² → 1.0/1.0; 5 м² → 0.9/0.85; 10 → 0.8/0.75;
  >20 → 0.75/0.65.
- Если собственные частоты «облицовка-каркас-крепёж» <1.5 Гц — динамический
  расчёт.
Проект Бугры этим и пользуется: −1.2 рядовая / −2.2 угловая зона →
76.2 / 139.7 кг/м² → шаги 1200/800.

**Пульсация:** ζ(ze)=ζ10·(ze/10)^(−α): 10 м → 0.76/1.06/1.78 (A/B/C);
предельные частоты, декременты (ж/б δ=0.3), корреляция ν(ρ,χ).

**Гололёд (р. 12) — прямо распространён на вентфасады ≥150 м:**
i′ = b·k·μ2·ρ·g (μ2=0.6, ρ=0.9 г/см³); толщина b по районам I–V:
3/5/10/15/20 мм (на 10 м); k по высоте: 10 м → 1.0, 100 м → 2.0; ветер на
обледенелые элементы = 25% w; γf=1.3.

**Температурные (р. 13, кратко):** для незащищённых конструкций; солнечная
радиация с коэффициентом поглощения (керамическая плитка 0.8, алюминий 0.5,
белый камень 0.45); γf=1.1.

## Следствия для модулей

1. **Зонирование фасада (блок A/B2!): угловые полосы шириной e/10 = зона
   повышенного отсоса** — алгоритм зон должен уметь выделять угловые зоны,
   т.к. в них другой шаг кронштейнов (живой пример: 800 vs 1200 в Бугры).
2. Чек-лист исходных данных (ТР п. 2.2) — валидация комплектности входа.
3. Пиковая формула + таблицы w0/k/cp = детерминированный расчёт давления по
   зонам — реализуемо в движке (но итоговые шаги всё равно утверждает
   прочностной расчёт системщика — наша роль: черновой подбор + проверка).
4. Ограничения-константы для валидатора: сталь ≤6.6 м / алюминий ≤3.6 м
   (направляющие), алюминий ≤100 м (высота), γm≥5 (анкер), отступ анкера
   ≥100 мм, глубины анкеровки 50/80/100, дюбели ≥5 шт/плиту, рандель ≥80,
   вентзазор 40 проект / 20 локально.
