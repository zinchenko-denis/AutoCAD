Инструкция для Германа. PDF-версия отдана Денису для пересылки.

ставятся у ПРАВОГО ВЕРХНЕГО угла участка, текст внутрь (было — в

## Установка (5 минут, один раз)

1. Скачать: https://github.com/zinchenko-denis/AutoCAD/releases/download/latest/AFacades.bundle.zip
2. Распаковать. Папку `AFacades.bundle` положить в
   `%APPDATA%\Autodesk\ApplicationPlugins\`
   (вставьте путь прямо в адресную строку Проводника).
3. Перезапустить AutoCAD. В командной строке появится:
   `AFacades загружен (сборка DLL от ДД.ММ.ГГГГ ЧЧ:ММ)`.
   **Эта дата — версия сборки; указывайте её в каждом сообщении с
   замечаниями.**

## Что делает ATFZONE (этап 1: зоны и площади)

По вашему ТЗ: контуры участков облицовки → слой с именем облицовки,
штриховка с вычетом проёмов, марка и площадь на чертеже, таблица площадей
и погонажей, файл зон для следующих модулей (раскладка, подсистема).

## Работа по шагам

1. Обведите замкнутыми полилиниями: внешние контуры участков облицовки
   и контуры проёмов (окна/двери) внутри них. Слой/цвет линий не важны.
   Дуговые сегменты (арки) поддерживаются.
2. Команда **ATFZONE** → выберите ВСЁ одной рамкой (внешние контуры и
   проёмы вместе; можно несколько участков сразу). Программа сама
   разберёт, что во что вложено: контур внутри контура = проём.
3. В диалоге:
   - **Наименование облицовки** — например «керамогранит идальго 600х600»
     или «штукатурка по утеплителю 150 мм». Станет ИМЕНЕМ СЛОЯ; контуры
     и штриховки переедут в этот слой. Список запоминает введённое.
   - Префикс и начальный номер марок зон (Ф-1, Ф-2, …).
   - Штриховка (ANSI31/SOLID/…), масштаб, цвет (номер ACI 1–255).
   - Высота текста марок/таблицы, мм.
   - Галки: вставить таблицу; сохранить JSON рядом с чертежом.
4. OK → укажите точку вставки таблицы.

## Что получится

- Слой с именем облицовки; в нём — контуры, штриховки (с «дырами»
  проёмов), марки зон с площадью нетто.
- Таблица: Марка | Облицовка | S участка | S проёмов | S облицовки |
  Отливы, м.п. | Откосы, м.п. — по зонам + ИТОГО.
  Отливы = нижние кромки проёмов; откосы = верх + бока. Кромка проёма,
  лежащая НА границе участка (дверь в пол), в отливы не попадает.
- Файл `<имя чертежа>_fzones.json` рядом с DWG — машиночитаемые зоны
  (вход будущей раскладки и подсистемы). При повторных запусках зоны
  добавляются/обновляются по маркам.
- Кривые контуры не пропадают молча: команда пишет в командную строку,
  какой контур отвергнут и почему (незамкнут, самопересечение, проём
  вылез за контур и т.п.).
- Марки зон идут СНИЗУ ВВЕРХ и СПРАВА НАЛЕВО (ряды определяются
  автоматически по низу зон).
- Данные каждой зоны хранятся на её штриховке и марке — ведомость можно
  собрать в любой момент позже.

## ATFTABLE — ведомость потом (и выгрузка в Excel)

1. Команда **ATFTABLE** → выберите штриховки и/или марки нужных зон
   (можно рамкой; чужие объекты игнорируются).
2. «Куда вывести ведомость [Чертеж/Ексель/Оба]»: Чертеж — таблица на
   чертеже (высота текста → точка вставки); Ексель — файл .xlsx (диалог
   сохранения, по умолчанию `<имя чертежа>_ведомость.xlsx` рядом с DWG);
   Оба — и то и другое. Строки в порядке номеров марок.
3. Если контур зоны двигали ПОСЛЕ обсчёта, фактическая площадь штриховки
   разойдётся с сохранённой — зона попадёт в ведомость с пометкой «*» и
   предупреждением в командной строке: перезапустите ATFZONE по ней.

## Ограничения v1 (сознательные)

- Контуры — только полилинии (LWPOLYLINE). Круглые/эллиптические проёмы —
  в следующей версии (пока обведите полилинией с дугами).
- Единицы чертежа — миллиметры.
- Кнопок в ленте пока нет — команда с клавиатуры: ATFZONE.
- Захватки: зоны можно резать на участки любым удобным дроблением
  контуров; отдельный инструмент деления «как угодно» — следующий шаг.
