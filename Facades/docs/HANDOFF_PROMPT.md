# Исторический промт передачи фасадного проекта

Этот августовский промт больше не используется для начала новой сессии.
Его старые команды подготовки среды и указания о ведении NEXT удалены
из рабочей версии; они не соответствуют нынешним правилам проекта.
Полный прежний текст сохранён [в истории Git](https://github.com/zinchenko-denis/AutoCAD/blob/42e9c1e7973fc4536be8597c94bd22655f1f43d7/Facades/docs/HANDOFF_PROMPT.md).

Для продолжения работы прочитайте:

1. [CLAUDE.md](../../CLAUDE.md) — правила, область изменений и сохранность данных.
2. [CURRENT_MILESTONES.md](../../docs/CURRENT_MILESTONES.md) — текущий статус,
   проверенный код, ограничения и следующий шаг.
3. [TESTING.md](../../docs/TESTING.md) — необходимые проверки и публикация.

Для инженера: [полное руководство Word](../../docs/user/Facades_User_Manual.docx)
и [скачивание с GitHub и установка на AutoCAD 2024](../../docs/user/INSTALL_AUTOCAD_2024.md).
