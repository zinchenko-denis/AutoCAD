## Грабли (кровью, НЕ ПОВТОРЯТЬ)

1. mcs --parse ≠ компилятор: ловит только синтаксис. Полный компилятор = CI check на каждый пуш ветки. При переносе кода грепать ВЫЗОВЫ хелперов против ОПРЕДЕЛЕНИЙ **и РЕФЫ CSPROJ**: dynamic требует `<Reference Include="Microsoft.CSharp" />` (CS0656, красный check 29.07 — FacadesClassic по паттерну ClassicUi ATableSpec, а реф был только у ATableSpec).
2. ДУБЛЬ КЛЮЧА в инициализаторе словаря не ловит ДАЖЕ полный компилятор — скан дублей после каждой правки payload/meta (скрипт в журналах; вложенные словари в одном выражении дают ложные срабатывания — проверять глазами).
3. WebFetch github.com = STALE-КЭШ ЧАСАМИ; api.github.com перехватывается прокси сессии («add_repo» — не наш механизм, не воевать). Статус сборки/релиза — только скринами/логами Дениса. Максимум один повторный пуш за заход.
4. Прокси может резать и токен-в-URL push монорепо (403) → extraHeader Basic (протокол выше). releases/download тоже резался — ассеты не скачать.
5. DWG читать aspose-cad НАПРЯМУЮ (tools/dwg_probe.py, инструкция внутри). НЕ конвертировать в DXF. Имена динпараметров из DWG не извлекаемы — читать в рантайме AutoCAD (DynamicBlockReferencePropertyCollection; паттерн InsertRailBlock: Double-свойство с max значением).
6. PromptKeywordOptions — ТОЛЬКО классический конструктор (messageAndKeywords, globals), дефолт по не-OK/пустому. Русские кейворды без «ё».
