## Репо, токен, первое действие

Монорепо ПУБЛИЧНЫЙ (осознанно). Токен (classic, repo) приложен рядом с
этим промтом. Гигиена ЖЕЛЕЗНО: не коммитить, не писать в файлы, в
выводах маскировать `| sed -E 's/ghp_[A-Za-z0-9]+/ghp_***/g'`.

новый, работать локально.


Push: токен-в-URL прокси может резать → Basic extraHeader:
`AUTH=$(printf 'x-access-token:TOKEN'|base64 -w0); git -c
http.extraHeader="Authorization: Basic $AUTH" push
https://github.com/zinchenko-denis/AutoCAD.git feat/auto-reactor`.
Перед КАЖДЫМ пушем fetch+rebase; после пуша `git fetch origin`.
Коммиты unsigned, префиксы нвф:/docs:/ci:, метки заходов датами
(26.07d — последняя; сквозные буквы по дню).

## Протокол «Собираем» (полностью — ATableSpec NEXT, ГРАБЛИ-4/5)

git fetch+rebase → `git branch -f build-trigger feat/auto-reactor` →
checkout → в build.yml `branches: [ main ]` → `[ main, build-trigger ]`
верхним коммитом → push --force (extraHeader) → назад → fetch. ОДИН
пуш; статус смотрит Денис ГЛАЗАМИ (скрины); красный → просить ТОЧНЫЙ
ЛОГ шага. build.yml собирает ВСЕ ПЯТЬ бандлов с ветки. Чужой свежий
build-trigger (<15 мин) не перетирать.

## Грабли (кровью, НЕ ПОВТОРЯТЬ)

1. mcs --parse ≠ компилятор: ловит только синтаксис (CS0103 SafeStr,
   23.07). Полный компилятор = check на каждый пуш ветки. При
   переносе кода грепать ВЫЗОВЫ хелперов против ОПРЕДЕЛЕНИЙ.
2. ДУБЛЬ КЛЮЧА в инициализаторе словаря не ловит ДАЖЕ полный
   компилятор (краш ATCLAD 23.07: «hjoints» дважды → ArgumentException
   у Германа) — скан дублей после каждой правки payload/meta
   (скрипт в журналах сессий).
3. WebFetch github.com = STALE-КЭШ ЧАСАМИ. Статус сборки/релиза —
   только скринами Дениса. Максимум один повторный пуш за заход.
4. Прокси среды режет api.github.com И releases/download (обе формы
   auth, 403) — ассеты не скачать; состав latest = хронология
   зелёных publish + скрины Дениса.
5. DWG читать aspose-cad НАПРЯМУЮ (tools/dwg_probe.py, инструкция
   внутри: pip aspose-cad --break-system-packages + libssl1.1 deb +
   DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1). НЕ конвертировать в DXF
   (получается R12, 2 ГБ, блоки взорваны). Имена динпараметров из
   DWG не извлекаемы — читать с образца в рантайме.
6. PromptKeywordOptions — ТОЛЬКО классический конструктор
   (messageAndKeywords, globals), дефолт по не-OK/пустому результату;
   Keywords.Add/Default/AllowNone РОНЯЛИ компиляцию (18.07r).
   Русские кейворды без «ё».
7. Новые AutoCAD-API — по прецедентам. Уже прошли полный компилятор:
   BlockTableRecord-создание, Polyline.AddVertexAt, Circle ctor,
   RotatedDimension, GeometricExtents, DynamicBlockReferenceProperty,
   Erase/UpgradeOpen/Highlight, лента ComponentManager/RibbonTab/
   RibbonPanel/RibbonButton, PromptPointOptions.AllowNone.
8. Движки stdlib-only (PyInstaller onefile; __file__ уходит в temp —
   ресурсы искать у sys.executable/_MEIPASS, паттерн systems.json);
   ezdxf только в тестах; юниты `PYTHONUTF8=1 python3 -m unittest`
   ИЗ каталога engine + скрипты test_*.py отдельно.
9. Copy-paste зоны наследует метки — на копии сначала ATFZONE,
