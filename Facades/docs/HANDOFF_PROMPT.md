### Новые грабли сессии 30.07

14. **ЛОВУШКА ПОДСТРОКИ при патче:** строка с отступом 16 является ПОДСТРОКОЙ такой же строки с отступом 20 → `s.count(o)==2` даёт ложное «нашли оба места», а `replace` ломает отступы. Патчить каждый отступ ОТДЕЛЬНО, якорь брать с полным отступом (`grep -n ... | cat -A`).
15. **`git checkout <file>` откатывает ВСЁ**, включая удачные правки того же файла. **Коммитить после КАЖДОГО зелёного блока**, до экспериментов.
16. **Вывод с кириллицей ломает bash_tool** («invalid UTF-8 data») — прогонять через `LC_ALL=C tr -dc '[:print:]\n'`; длинные коммит-месседжи с кириллицей давать через `git commit -F -` + heredoc, а не `-m`.
17. **НЕ строить фикс на собственной синтетике.** Задвоение кляммеров «воспроизвелось» на выдуманных швах со сдвигом 150 — механизм оказался другим. Юниты (FR3) отбили две неверные гипотезы подряд. Сначала воспроизвести на РЕАЛИСТИЧНЫХ числах, потом чинить.
18. **Раскадровка видео:** `ffmpeg -vf "fps=1/5,crop=...,scale=...,drawtext=text='%{eif\:(n*5)\:d}s',tile=5x5"` — контактные листы для навигации, потом прицельные зумы (`-ss T`, crop+lanczos+unsharp). Если видео несколько — проверить, не СКВОЗНОЙ ли транскрипт (сумма длительностей = длина текста), и давать тайм-коды как «видео N, м:сс».
