## Протокол «Собираем» (кратко; полностью — ATableSpec NEXT ГРАБЛИ-4/5)

`git branch -f build-trigger feat/auto-reactor` (ПОСЛЕ fetch+rebase!) →
checkout → в build.yml `branches: [ main ]` → `[ main, build-trigger ]`
верхним коммитом → push --force → вернуться на feat/auto-reactor.
ОДИН пуш; статус смотрит Денис глазами в Actions (WebFetch врёт кэшем
часами); красный run → просить у Дениса ТОЧНЫЙ ЛОГ шага с телефона
(GitHub app → run → шаг) — по нему чинить, не гадать. build.yml собирает
ВСЕ ТРИ бандла с ветки. build-trigger пушит только сессия, получившая
«Собираем»; свежий чужой build-trigger (<15 мин) не перетирать.

## Грабли C#/среды (кровью)

- WPF-рефы (PresentationCore/Framework, WindowsBase, System.Xaml)
  ОБЯЗАТЕЛЬНЫ в csproj любого плагина с ShowModalDialog/
  StartUserInteraction — иначе CS0012 'Window' (18.07r).
- Новые AutoCAD-вызовы — только по боевым прецедентам соседей (grep по

  (apt) полноценно компилит не-AutoCAD файлы (WinForms/Compression).

  русские кейворды ок.

  инструкция в утилите). Имена динпараметров из прокси не извлекаемы —
  читать с образца в рантайме.
- ezdxf — только в тестах, в движки НЕ тащить (PyInstaller stdlib-only).
- Питон-юниты: PYTHONUTF8=1; `python3 -m unittest` ИЗ каталога engine.
- Денис может дать точный лог CI с телефона — просить сразу.
