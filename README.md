# AutoCAD — надстройки и автоматизация

Монорепо инструментов автоматизации AutoCAD: спецификации, генерация
конструкций, фасадное направление (НВФ). Каждый модуль — в своей
подпапке, самодостаточен (исходники, движок, сборка, документация) и
ставится отдельным бандлом. Три фасадных бандла используют общие данные и
обновляются вместе.

## Модули

| Модуль | Что делает | Команды | Статус |
|---|---|---|---|
| [`ATableSpec/`](ATableSpec/) | Ведомости/спецификации из блоков без СПДС, раскрой, авто-пересчёт | `ATSPEC`, `ATSPECREPORT`, `ATSPECEDIT`, `ATSPECEXPORT`, `ATSPECUPDATE` | боевой (Алексей) |
| [`ABlockGen/`](ABlockGen/) | Витражи/конструкции из блоков по чертежу АР | `ATVITRAGE`, `ATVITRAGEAR` | боевой (Алексей) |
| [`Facades/`](Facades/) | НВФ этап 1: зоны фасадов, площади, сводная | `ATFZONE`, `ATFTABLE` | фасадный пилот (Герман) |
| [`AClad/`](AClad/) | НВФ этап 2: раскладка облицовки (разбежка, принудительные русты, раскраска по образцу); ATCLAD — прежняя, для старых чертежей | `ATTILE`, `ATCLADDIM` (`ATCLAD` — набором) | пилот (Герман) |
| [`AFrame/`](AFrame/) | НВФ этапы 3–4: подсистема (кронштейны, направляющие, кляммеры) + расчёт несущей способности | `ATFRAME`, `ATFRAMEDIM`, `ATDEDUP` | пилот (Герман) |

Архитектура всех модулей — гибрид: C#-плагин (.NET Framework 4.8,
собран под AutoCAD .NET SDK 2021 — AutoCAD 2021–2024: Герман работает в
2024, Алексей — в 2021; манифесты фасадных бандлов с 23.09 — R24.0–R24.3,
у ATableSpec/ABlockGen пока шире) +
замороженный Python-движок (PyInstaller; фасадные движки — только
стандартная библиотека, ATableSpec — с ezdxf/PyYAML/openpyxl), обмен JSON
через временные файлы. Установка = одна папка бандла в
`%APPDATA%\Autodesk\ApplicationPlugins\`, без доустановки софта. Рядом с
DLL каждого бандла — `build-info.json` (номер сборки, коммит).

## Готовые сборки

Для установки фасадов откройте выпуск с номером, указанным Денисом,
и скачайте три архива из раздела **Assets**. Пошаговая инструкция —
[скачивание и установка](docs/user/INSTALL_AUTOCAD_2024.md).
Состояние опубликованного установщика и исправлений в рабочей ветке —
[в текущем плане](docs/CURRENT_MILESTONES.md).

Релиз **[latest](https://github.com/zinchenko-denis/AutoCAD/releases/tag/latest)**
несёт пять отдельных архивов (обновляется при каждой сборке):

- `ATableSpec.bundle.zip`
- `ABlockGen.bundle.zip`
- `AFacades.bundle.zip`
- `AClad.bundle.zip`
- `AFrame.bundle.zip`

Каждая сборка дополнительно публикуется неизменяемым релизом
`build-N` (номер прогона CI) — для отката и воспроизведения истории. С
24.09 тег `build-N` стоит на собранном коммите (раньше — на старом `main`:
у `build-92…95` «Source code» не совпадает с бандлами, исходники этих
сборок — коммиты из названий релизов). Публикация — только после тестов.

Установка: скачать три фасадных архива одного выпуска → распаковать папки `*.bundle` в
`%APPDATA%\Autodesk\ApplicationPlugins\` → перезапустить AutoCAD.
Три фасадных бандла (AFacades/AClad/AFrame) обновлять вместе — меню
общее.

## Ветки

- `main` — релизные срезы (стабильное состояние);
- `feat/auto-reactor` — рабочая ветка всех модулей (HEAD разработки);
- `build-trigger` — историческая техническая ветка; текущую сборку запускают
  через `workflow_dispatch` на `feat/auto-reactor` по команде «Собираем».

## Документация

[Текущий план](docs/CURRENT_MILESTONES.md) различает изменения в рабочей
ветке, опубликованный установщик и фактическую проверку AutoCAD.
[Два руководства для проектного отдела](docs/user/README.md) содержат
полный рабочий процесс и отдельную короткую установку. Архивные
[комплект build-105](docs/pilot_release_0110/README.md) и
[руководство прежнего выпуска](docs/facades_beginner_3009/) сохранены
для воспроизведения истории.

История проекта — [хронология](docs/CHRONOLOGY.md),
[индекс](docs/CHRONOLOGY_INDEX.md) и `<модуль>/docs/NEXT.md`.
Старые формулировки «следующий шаг» относятся к датам этих записей.
Новые подробные журналы проверок сохраняются в артефактах CI.

## Исходный код для разработчиков

Для исходников — кнопка **Code → Download ZIP** вверху страницы, либо:
```
git clone https://github.com/zinchenko-denis/AutoCAD.git
```

Этот ZIP не устанавливает программу в AutoCAD. Готовые плагины скачиваются
из **Releases → Assets**, как описано выше.
